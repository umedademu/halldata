2. 高内容日の定義

設定列は存在しないため、設定列を使った検証はできません。今回は、実戦で後日判定できる「高設定っぽい日 / 高内容日」を以下で定義しました。

採用した高内容日

G数 >= 5,000G
かつ 合成確率 <= 1/135
かつ RB確率 <= 1/300

理由は、ネオアイムジャグラーEXの目標値が「合算1/130以下、RB1/270以下、機械割104〜106%付近」なので、RBだけでなく合算も必ず条件に入れ、G数の信頼度も確保するためです。RB1/270まで絞ると件数がやや少なくなりすぎたため、検証ラベルとしてはRB1/300までを拾い、最終バックテストでRB1/270に近づくかを別で確認しました。

# 重要：単純加点式に寄せすぎないこと

最終的に100点満点の狙い度は作ってください。

- 条件B単独で強い
- 条件C単独で強い
- A+Bの組み合わせで初めて強い
- Aは強いが、BやCは不要
- Aがある時だけBが有効
- Aがない時だけBが有効
- Aは強いが、危険条件Dがあると弱くなる

- ルートA：沈み返しルート
- ルートB：不発据え置きルート
- ルートC：ローテーションルート
- ルートD：周辺状況・取り残されルート
- ルートE：総合加点ルート

のようにして構いません。

つまり、

A+B+Cの合計でしか高得点にならない設計ではなく、
A単独で強いならAルートだけで高得点になる設計にしてください。

1. 各主要条件の単独成績
2. 各主要条件が単独で成立した時の成績
3. Aあり・Bなし・Cなしのような「単独ルート」の成績

6. 単独条件で十分強いものを、総合点の低さで見送っていないか
7. 総合点は高いが、実際には危険条件で弱くなるパターンがないか

- 単独で狙える条件
- 複合した時だけ狙える条件
- 高スコアでも見送る条件
- スコアより優先すべきSランクトリガー
- 総合点は低めでも拾うべき例外条件

を分けて説明してください。
