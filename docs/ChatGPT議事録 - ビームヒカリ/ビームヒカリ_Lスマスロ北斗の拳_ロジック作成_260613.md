高内容日の代理定義

今回は以下を高内容日としました。

高内容日 = 当日G数 4,000G以上 かつ BB+RB合成 1/105以下

理由は、データ上で4,000G以上まで回された台のうち、合成1/105を超えるゾーンは差枚・勝率が急に弱くなり、1/105以内では「高内容っぽい見え方」と「実差枚」が両立しやすかったためです。

基本手順

11. 最終結論

この機種は、ローテーション狙いではなく、直近で沈んだ台・内容が悪く見えた台を返すクセが強いです。

ただし、毎日1位に座るだけでは機械割102.60%で、スマスロ系の目標104〜106%には届きません。
目標帯に届いたのは、狙い度1位で、70点以上、かつ2位との差が5点以上ある日だけに絞った場合です。

最終採用ロジックはこれです。

実戦採用条件：
狙い度70点以上
かつ 当日1位
かつ 2位との差が5点以上
かつ 危険条件2個未満

この条件のバックテストは、**156台、総差枚+49,922枚、平均+320.0枚、機械割105.76%、合成1/86.7、勝率40.4%**でした。

結論として、ビームヒカリのLスマスロ北斗の拳は、
**「沈み返し + 弱内容上げ + 処遇完了回避 + 次点差5点以上」**で狙うのが最も現実的です。

8. 最終結論

イベント日と通常日は別ロジックにするべきです。

イベント日は、前回ロジックに近い

「深い沈み + 極端弱内容 + 強化条件重複 + 前日プラス回避」
