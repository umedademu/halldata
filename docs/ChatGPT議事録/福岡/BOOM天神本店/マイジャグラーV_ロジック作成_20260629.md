以下は、CSVを読み込んで作った **BOOM天神本店・マイジャグラーV用の狙い台ロジック正本** です。
この回答では、プロンプトの指定どおり、途中分析よりも最後の **実装用正本** と **Codex貼り付け用 実装依頼** を実装の基準にしています。
また、CSV内の最新日は営業途中の可能性があるため除外し、当日前に分からない未来情報は狙い度計算に使っていません。

## 2. 高内容日の定義

CSVの `設定` 列は、最終ロジックの入力には使っていません。
代わりに、マイジャグラーVの設定別BB・RB確率から、各実績日の `設定4以上推定率`、`設定5以上推定率`、`設定3以下推定率` を計算しました。

### 設定推定率

| 指標       | 定義                       |
| -------- | ------------------------ |
| 設定4以上推定率 | 設定4推定率 + 設定5推定率 + 設定6推定率 |
| 設定5以上推定率 | 設定5推定率 + 設定6推定率          |
| 設定3以下推定率 | 設定1推定率 + 設定2推定率 + 設定3推定率 |

### 高内容ラベル

| ラベル  | 条件式                               |   |                                       |
| ---- | --------------------------------- | - | ------------------------------------- |
| 準高内容 | `games >= 3000 && (p4plus >= 0.45 |   | (rb_rate <= 320 && combined <= 145))` |
| 高内容  | `games >= 4500 && (p4plus >= 0.60 |   | (rb_rate <= 300 && combined <= 140))` |
| 強高内容 | `games >= 5500 && (p5plus >= 0.45 |   | (rb_rate <= 270 && combined <= 130))` |

この高内容ラベルは、狙い度を付ける当日ではなく、**前日以前の履歴**にだけ使います。

## 5. 完成した100点満点ロジック

ロジック名：
**BOOM天神本店_マイジャグラーV_内容継続スコア**

このスコアは、Webアプリの `機種別` 列に表示する全日共通スコアです。
日付が通常日かイベント日かはスコアに直接加点しません。イベント日は、別途 `特定日` 列の条件で見る想定です。

### 点数式

```text
score = 35

score += historyDays >= 21 ? 10 : (historyDays >= 14 ? 3 : -15)

score += highContentCount14 >= 5 ? 18
       : highContentCount14 >= 3 ? 14
       : highContentCount14 >= 2 ? 8
       : highContentCount14 == 1 ? 2
       : -6

score += highContentCount7 >= 3 ? 12
       : highContentCount7 == 2 ? 8
       : highContentCount7 == 1 ? 3
       : -4

score += highContentCount3 >= 2 ? 8
       : highContentCount3 == 1 ? 3
       : 0

score += strongHighContentCount7 >= 2 ? 10
       : strongHighContentCount7 == 1 ? 6
       : 0

score += daysSinceHighContent >= 1 && daysSinceHighContent <= 3 ? 5 : 0
score += daysSinceHighContent >= 4 && daysSinceHighContent <= 6 ? 9 : 0
score += daysSinceHighContent >= 7 && daysSinceHighContent <= 10 ? 4 : 0

score -= daysSinceHighContent > 20 ? 10 : 0

score += rbRate14 <= 320 && combinedRate14 <= 145 && games14 >= 35000 ? 10 : 0
score += rbRate7 <= 315 && combinedRate7 <= 142 && games7 >= 18000 ? 7 : 0

score += prev_p4plus >= 0.55 && prev_games >= 2500 ? 5 : 0

score += games14 >= 52000 ? 6
       : games14 >= 44000 ? 4
       : 0

score += games7 >= 27000 ? 4
       : games7 >= 22000 ? 2
       : 0

score += diff21 >= 3800 ? 6
       : diff21 >= 800 ? 3
       : 0

score += diff14 >= 3000 ? 5
       : diff14 >= 700 ? 2
       : 0

score -= historyDays < 21 ? 20 : 0
score -= highContentCount14 == 0 && historyDays >= 21 ? 12 : 0
score -= rbRate14 > 402 && historyDays >= 14 ? 8 : 0
score -= combinedRate14 > 163 && historyDays >= 14 ? 6 : 0
score -= games14 < 32380 && historyDays >= 14 ? 5 : 0
score -= daysSinceHighContent > 37 ? 6 : 0

score = min(100, max(0, round(score)))
```

### 指標定義

| 指標名                     | 計算式                       | 使う履歴範囲     | 欠損・低G数の扱い     | 未来情報を含まない理由  |
| ----------------------- | ------------------------- | ---------- | ------------- | ------------ |
| historyDays             | 台番ごとの過去有効日数               | 当該実績日の前日以前 | 欠損後は非アクティブ    | 当日実績を使わない    |
| prev_games              | 前営業日のG数                   | 前営業日1日     | 欠損なら0         | 前営業日終了時に既知   |
| prev_p4plus             | 前営業日の設定4以上推定率             | 前営業日1日     | G数不足なら推定率は低信頼 | 前営業日終了時に既知   |
| games7                  | 過去7有効日のG数合計               | 前日以前7日     | 欠損日は除外        | 当日実績を含まない    |
| games14                 | 過去14有効日のG数合計              | 前日以前14日    | 欠損日は除外        | 当日実績を含まない    |
| diff14                  | 過去14有効日の差枚合計              | 前日以前14日    | 欠損日は除外        | 当日差枚を含まない    |
| diff21                  | 過去21有効日の差枚合計              | 前日以前21日    | 欠損日は除外        | 当日差枚を含まない    |
| rbRate7                 | `games7 / RB7`            | 前日以前7日     | RB0なら∞扱い      | 当日RBを含まない    |
| rbRate14                | `games14 / RB14`          | 前日以前14日    | RB0なら∞扱い      | 当日RBを含まない    |
| combinedRate7           | `games7 / (BB7 + RB7)`    | 前日以前7日     | ボーナス0なら∞扱い    | 当日ボーナスを含まない  |
| combinedRate14          | `games14 / (BB14 + RB14)` | 前日以前14日    | ボーナス0なら∞扱い    | 当日ボーナスを含まない  |
| highContentCount3       | 過去3日の高内容回数                | 前日以前3日     | 欠損日は除外        | 当日高内容を含まない   |
| highContentCount7       | 過去7日の高内容回数                | 前日以前7日     | 欠損日は除外        | 当日高内容を含まない   |
| highContentCount14      | 過去14日の高内容回数               | 前日以前14日    | 欠損日は除外        | 当日高内容を含まない   |
| strongHighContentCount7 | 過去7日の強高内容回数               | 前日以前7日     | 欠損日は除外        | 当日強高内容を含まない  |
| daysSinceHighContent    | 前回高内容からの有効日数              | 前日以前       | 未発生なら大きい値扱い   | 当日結果を含まない    |
| rank                    | 同一実績日のスコア順位               | 同日アクティブ台   | score同点は台番昇順  | スコア自体が過去情報だけ |
| topGap                  | 日別1位score - 2位score       | 同日アクティブ台   | 1台のみなら0       | スコア自体が過去情報だけ |

## 6. サブ条件・信頼度ラベル

### 強化条件

| ラベル      | 条件式                                                                             | 意味                |
| -------- | ------------------------------------------------------------------------------- | ----------------- |
| 直近内容強    | `highContentCount14 >= 3 && highContentCount7 >= 1`                             | 近い履歴で設定4以上級を見せている |
| 前日内容強    | `prev_p4plus >= 0.75 && prev_games >= 2500`                                     | 前日が高内容寄り          |
| 直近稼働強    | `games7 >= 22000`                                                               | 店・客ともに見えている台      |
| イベント本命下地 | `event == true && prev_p4plus >= 0.75 && games7 >= 22000`                       | 特定日に再投入されやすい下地    |
| イベント紫A   | `event == true && prev_p4plus >= 0.75 && games7 >= 22000 && prev_games >= 5500` | 最終通常採用条件          |
| イベント紫B   | `event == true && prev_p4plus >= 0.75 && games7 >= 30000`                       | 自由度MAXの最優先候補      |

### 危険条件

| ラベル    | 条件式                                            | 意味          |
| ------ | ---------------------------------------------- | ----------- |
| 履歴不足   | `historyDays < 21`                             | 通常採用条件から除外  |
| 直近内容なし | `historyDays >= 21 && highContentCount14 == 0` | 放置台寄り       |
| RB弱い   | `rbRate14 > 402 && historyDays >= 14`          | 内容継続の根拠が弱い  |
| 合算弱い   | `combinedRate14 > 163 && historyDays >= 14`    | 高設定感が弱い     |
| 稼働不足   | `games14 < 32380 && historyDays >= 14`         | データ信頼度不足    |
| 長期空きすぎ | `daysSinceHighContent > 37`                    | ローテ期待より放置寄り |

### 見送り方針

通常日で `rank == 1` ではない台は、スコアが高く見えても基本は見送り寄りです。
イベント日でも、`prev_p4plus < 0.75` かつ `score < 80` の台は、強い条件が出た台より優先しません。

## 12. 実戦での使い方

優先順位は次です。

1. **イベント日なら、まず紫Bを見る**
   `prev_p4plus >= 0.75 && games7 >= 30000`

2. **紫Bがなければ紫Aを見る**
   `prev_p4plus >= 0.75 && games7 >= 22000 && prev_games >= 5500`

3. **紫A/Bがないイベント日は、score80以上・前日p4plus75%以上を参考にする**
   ただし広い条件は該当台が多いため、単独で全ツッパ条件にはしない。

4. **通常日はrank1だけ参考**
   通常日1位はRB 1/329.1で、マイジャグラー狙いとしては物足りない。イベント日ほど強くない。
