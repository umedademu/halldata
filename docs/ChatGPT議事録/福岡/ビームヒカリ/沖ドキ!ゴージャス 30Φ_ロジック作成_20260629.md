# 2. 高内容日の定義

この機種はジャグラー系ではなく沖ドキ系なので、RB確率を主指標にはしない。
機械割・平均差枚・勝率・G数・ボーナス合成を併記する。

履歴指標に使う内容定義：

準高内容：
G >= 1500 && diff >= 1000

高内容：
G >= 2000 && (diff >= 2000 || (diff >= 500 && combined <= 145))

強高内容：
G >= 3000 && diff >= 3000 && combined <= 140

combined：
G / (BB + RB)
BB + RB == 0 の場合は 99999 とする。

highContent：
上記の「高内容」と同義。
highCntN は、直近N営業日の highContent 回数。
