## 2. 高内容日の定義

スマスロ系なので、AタイプのRB推定ではなく、差枚・G数・RB確率相当・機械割で「高内容」を定義しました。

```text
高内容 highContent:
g >= 3000 && (diff >= 1500 || rbRate <= 260 || payout >= 106)

強高内容 strongHigh:
g >= 3500 && (diff >= 3000 || rbRate <= 230 || payout >= 110)
```

`rbRate = g / rb`、`payout = 100 + diff / g / 3 * 100` です。

## 3. 設定師のクセ仮説

一番強かったのは、単純な凹み上げではなく、**前回高内容から4〜13営業日空いた台を、直近7日G数が過熱しすぎていない状態で再投入するパターン**でした。

次に、100点スコアで高評価かつ危険条件が0の台が安定しました。逆に、75点以上でも危険条件が1つ以上ある台は、37件で機械割94.87%まで落ちたため、見送り条件として採用します。

## 12. 実戦での使い方

最優先は **自由MAX_間隔4-13_G7過熱なし_危険0** です。これが出た日は、score順位より優先して候補にします。

次に **75点以上＋危険0**、その次に **70点以上＋危険0** を見るのが現実的です。`65点以上`、`70点以上`、`75点以上` の単独条件は、危険条件混入で成績が落ちるため参考表示に留めます。

`75点以上危険あり` は見送りです。

## 13. 最終結論

この機種は、単純な凹み狙いよりも、**前回高内容からの再投入間隔** と **直近の過熱しすぎ回避** が強いです。
主軸は自由度MAX条件、補助として100点ロジックの70点以上＋危険0、75点以上＋危険0を使う構成が最も実戦向きです。
