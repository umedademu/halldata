## 実装した最終選定

1. 既存のRB優先条件に該当する日は、その候補を空間配置より先に採用する。
2. 該当しない日は、通常日用またはイベント日用の機種点順位と、選択中の店舗共通順位を統合する。
3. ビームヒカリ1.0Sは前2日BB+RB回数の少ない順を1位から40位まで連番にし、同数時は機種別順位を優先する。
4. 統合基礎値の上位14台から、通常日は5台、イベント日は8台の全配置を評価する。
5. 同列の距離1・2だけを減点し、配置支持率1位と2位の比が1.05以上の日だけ1台を採用する。

RB優先条件、空間配置、見送りを機種別評価の最終段階に置いたため、狙い度ランキングとバックテストは同じ `matchesAdoption` を使う。

- RB優先の21件は、件数から勝率まで一致した。
