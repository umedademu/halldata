# ビームヒカリ / 台データオンラインAT補完 仕様決定記録 2026-07-27

## この文書の位置づけ

2026年7月27日の会話で決まった実装条件の要約です。会話原文の再現ではありません。

## 依頼内容

- サイトセブンを利用できず、台データオンラインへ振り替えている店舗で、台番別詳細の週間当たりグラフにあるAT回数も取得したい。
- みんレポの本体データを優先する既存仕様は維持し、台データオンラインのATだけは消さずに残したい。
- 機種によってBB、RB、ATの意味が異なるため、使用されていないBBまたはRBの枠へATを表示したい。
- BB、RB、ATの3列をすべて使用する機種ではATを表示・計算へ加えない。
- 通常のみんレポ定期取得だけを行った場合も、対象店舗ではATだけを台データオンラインから補完したい。
- 判定は機種共通ではなく、店舗と機種の組み合わせで一度記憶したい。
- 5円、5.6円などの低貸しスロットは無視したい。
- `サイトセブン取得機種` でOFFにした機種は、本体確認とAT取得の両方から外したい。
- ATはBB、RBと内部的に統合せず、生の値を分離保存し、狙い度ランキングやバックテストでは計算用ボーナス回数へ反映したい。
- 後から考え方を変えた場合に、生のBB、RB、ATへ戻せる状態を保ちたい。

## 決定

- 生のBB、RB、ATは分離保存する。
- Web表示、BB率、RB率、合成、狙い度、設定推定、バックテストだけ、店舗・機種ごとの判定に従ってATをBBまたはRBへ加算する。
- 3列使用機種は生ATを保持し、現在の表示・計算では無視する。
- 手動の台データオンライン取得では、選択済みの20円相当の非ジャグラー機種についてG数、生BB、生RBも取得する。
- みんレポ取得後の自動補完では、本体を再取得せず、選択済み機種のATだけを取得する。
- 週間グラフの日付ラベルをそのまま使い、直近8日を上限とする。

詳細な運用仕様は `docs/運用ルール/台データオンラインAT補完仕様.md` を参照します。
