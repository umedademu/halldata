# ビームヒカリ ネオアイムジャグラーEX 空間選定切替 議事録

## 結論

ビームヒカリのネオアイムジャグラーEXにある機種別最終選定へ、空間選定を使用するかどうかの切り替えを追加する。

- 対象画面は狙い度ランキングとバックテスト
- 既定は不使用
- 両画面で前回設定を別々に保存・復元する
- 不使用時は空間配置の組み合わせ計算を行わず、従来の順位を使う
- 使用時は空間選定後の最終順位をランキングとバックテストの両方へ反映する
- 使用時の共通条件に機種内順位がある場合も、空間選定後の最終順位を使う
- バックテストの設定分布は既定で非表示にする

## 実装上の位置付け

空間選定は、店舗共通ロジックへ直接組み込む機能ではない。既存の機種別評価が持つ最終選定の仕組みに設定を追加し、ビームヒカリのネオアイムジャグラーEXに登録済みの最終選定だけが反応する。

そのため、ビームヒカリ式1.0、ビームヒカリ1.0Sなど、どの共通ロジックを選んでも切り替えは機能する。使用時は選択中の共通ロジックの順位を材料に空間選定し、不使用時は共通ロジックと機種別ロジックの従来計算だけを行う。

## バックテストとの関係

狙い度ランキングとバックテストは同じ機種別最終選定を通る。したがって、空間選定を使用したバックテストでは最終順位が機種内順位条件にも反映され、不使用のバックテストでは従来順位を使う。

2026-07-14の空間配置照合結果を再現する場合は、バックテストで `ネオアイム空間選定` を使用する。

## 確認内容

- 不使用時に最終選定を付与せず、入力順位を維持する単体試験
- 使用時に空間選定の最終順位へ並び替える単体試験
- 他店舗や対象外機種へ影響しない単体試験
- 設定分布が未指定なら非表示、明示的に指定した時だけ表示する単体試験
