ただし、同列の近距離回避そのものは、データ上は主に距離1・2で終わっています。より広い範囲のバランスは、半径を3・4へ広げるのではなく、全体配置として別に扱うべきです。

6. 完成した「全体配置モデル」

共通1.0Sの本線は、ネオアイムについて全日、

前2日BB+RB合計が機種内最少
かつ
前2日差枚がマイナス

という条件です。

店舗共通ロジック作成_1.0S_20260706

この共通ロジックと、このスレの機種別スコアを次のように統合します。

6-1. 2ロジックを同じ尺度に変換

各日40台について、

M = (41 - 機種別スコア順位) ÷ 40

とします。

機種別1位なら1.000、40位なら0.025です。

共通ロジック側は、前2日BB+RBの少ない順を使います。

前2日差枚 < 0 の場合：
C = (41 - 前2日BON少なさ順位) ÷ 40

前2日差枚 >= 0 の場合：
C = 0

共通1.0S本来の最少台は、Cが最大になります。

統合基礎値は、

B = max(M, C) + 0.20 × min(M, C)

です。

これにより、

どちらか一方だけ非常に強い台を残す

両方のロジックで強い台には少しだけ一致ボーナスを与える

という形になります。

A+Bの単純平均ではないので、片方のロジックだけがドンピシャの台を潰しにくい設計です。

6-2. 候補14台を残す

Bが高い上位14台を、配置候補にします。

上位14台へ実際に座るわけではありません。

低順位候補が上位候補のすぐ近くに固まっているかを判定するため、最終着席候補より広く取っています。

6-3. あり得る配置セットをすべて作る
通常日

上位14台から5台を選ぶ全組合せです。

14C5 = 2,002通り
イベント日

上位14台から8台を選ぶ全組合せです。

14C8 = 3,003通り

各配置セットをまとめて評価します。

6-4. 配置セットの評価式
通常日
配置評価F(S)
= セット内各台のB合計
- 1.42 × 同列・距離1ペア数
- 0.44 × 同列・距離2ペア数
イベント日
配置評価F(S)
= セット内各台のB合計
- 0.42 × 同列・距離1ペア数
- 0.13 × 同列・距離2ペア数

距離3以上や真向かいには、固定減点を付けません。

6-5. 全配置から各台の「配置支持率」を出す

各配置セットの重みを、

重み = exp(F(S))

とします。

そして各台について、

配置支持率P(i)
=
その台を含む全配置の重み合計
÷
全配置の重み合計

を計算します。

最終的には、Pが最大の台を1位とします。

この方式で何が起きるか

例えば、

872：基礎値1位
873：基礎値2位
875：基礎値3位
1020：基礎値4位

だったとします。

872・873・875は同じ狭いエリアなので、多くの有力配置では、この3台のうち1台程度しか採用されません。

そのため、

872を含む配置
873を含む配置
875を含む配置

へ支持が分散します。

一方、1020が孤立していれば、872・873・875のどれを選ぶ配置でも、1020が同時に採用される可能性があります。

その結果、

基礎値では4位の1020
↓
配置支持率では1位

という昇格が自然に起きます。

これが、梅田さんがイメージしている、

全体4〜5位でも、他の投入候補と配置的に両立しやすい台の方が優先される

を数式化したものです。

13. 具体例への回答
872・873・875が上位、1020が4位の場合

この場合は、

872・873・875：
同じエリアの1枠を奪い合うため、
各台の配置支持率が分散する

1020：
離れた位置で他候補と両立しやすいため、
多くの有力配置に含まれる

となります。

1020が全体4位でも、配置支持率1位へ昇格する可能性があります。

これは今回の全体配置モデルで直接扱えます。

872が90点、1002が85点の場合

872と1002は同じ列ですが、物理的にかなり離れています。

両方を同じ高設定配置セットに入れても近接ペナルティは発生しません。

1002が候補だから872を降格

両方を同じ配置セットに入れて構いません。

最終結論

前回の「距離2以内に競合候補がいれば降格」は、方向性自体は合っていますが、固定半径の二値フィルタとしては粗すぎました。

今回の再検証から、適切な扱いは次のとおりです。

通常日：
隣接を強く避ける
1台挟みを中程度に避ける
距離3以上は一律に避けない

イベント日：
隣接だけ軽く避ける
距離2の回避はごく弱い

そして、究極的には1台対1台の距離ではなく、

イベント日は8台

の高設定配置セットを全組合せで考え、各台が有力配置に含まれる割合を出す方法が適切です。

実戦では、

1. RBゲートがあれば、ゲートを最優先
2. ゲートがなければ全体配置モデル
3. 配置支持率1位÷2位が1.05以上なら打つ
4. それ未満は見送る

となりました。
