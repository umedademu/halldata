# 3. 見えたクセ

この店舗のゴーゴージャグラー3は、単純な「前日凹み」よりも、**REGが切れている、直近に大きな見せ場がない、複数日で沈んでいる台を返す動き**が強く出ました。

特に強かったのは次の順です。

| 強さ | パターン          | 内容                      |
| -: | ------------- | ----------------------- |
|  1 | REG切れ＋5日急沈み   | 前日REGが重く、直近5日の沈み角度が強い台  |
|  2 | REG切れ＋7日沈み    | 前日REGが重く、直近7日でも沈み角度が残る台 |
|  3 | REG切れ＋直近見せ場不足 | 前日REGが重く、直近7日最大差枚が弱い台   |
|  4 | 長期沈み＋goodRB空白 | 21日沈み、かつ10日以上goodRBがない台 |
|  5 | 4連勝以上は危険      | 直近で連勝処遇されている台はRB・合算とも悪化 |

# 13. 実戦での使い方

最優先は **自由MAX_三重深沈み** です。これが出たら点数順位より優先して本命扱い。

次に **紫 → 赤 → 緑 → 黄** の順に見ます。
ただし、`winStreak >= 4` の台は処遇完了寄りなので、たとえ点数が高く見えても見送りです。

100点満点ロジックは、毎日の全台ランキングと相対感を見るために使い、実際に座る根拠は段階条件と自由MAX条件を優先します。
