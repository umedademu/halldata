## 反映内容

本質的な加点要素、危険判定、採用条件の考え方は変更せず、最終表示点だけを圧縮した。

途中の点数で折れ曲がりを作らず、元点全体を同じ倍率で縮める。元120点を表示100点として扱う。

採用条件は圧縮前の旧100点満点を見て判定し、既存バックテストの条件範囲を大きく変えない。

| 元点 | 表示点 |
| --- | --- |
| 75 | 63 |
| 80 | 67 |
| 90 | 75 |
| 95 | 79 |
| 100 | 83 |
| 110 | 92 |
| 114 | 95 |
| 120 | 100 |
| 130 | 100 |

## 採用条件の扱い

70点以上、75点以上、80点以上のような条件は、圧縮前の旧点数を見て判定する。

今回の変更は「100点満点で上側が潰れていた表示」を直す目的であり、バックテスト条件そのものを作り直す変更ではない。
