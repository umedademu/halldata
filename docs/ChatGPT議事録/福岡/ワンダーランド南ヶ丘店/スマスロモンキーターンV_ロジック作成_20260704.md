以下、CSVから作った**実装用の正本**です。
このプロンプトは「分析レポート」ではなく、あとでCodexが迷わずWebアプリへ実装できる正本を作ることが目的なので、その前提で、条件式・集計値・採用区分を固定しました。
また、CSV内の最新日行は除外し、「狙度」「次差」は最終ロジックの説明変数に使っていません。

通常採用・見送り条件の**全件該当一覧**は、行数が多いため照合用Markdownにも切り出しています。

## 2. 高内容日の定義

スマスロモンキーターンVはAタイプではないため、RBではなく**G数・差枚・機械割**を高内容の代理にしました。

| ラベル  | 条件式                          | 用途            |                               |                    |
| ---- | ---------------------------- | ------------- | ----------------------------- | ------------------ |
| 高内容  | `(G >= 5000 && diff >= 1500) |               | (G >= 4000 && payout >= 104)` | 前回高内容からの日数、直近高内容回数 |
| 強高内容 | `G >= 5000 && diff >= 2500`  | 処遇完了・強い見せ場の検出 |                               |                    |
| 準高内容 | `(G >= 3000 && diff >= 1000) |               | (G >= 4000 && payout >= 102)` | 直近の見せ場量            |

`payout = 100 + diff / G / 3 * 100`

## 3. 設定師のクセ仮説

一番強かったのは、**前回高内容から5〜21営業日ほど空き、直近7日の稼働が中程度、前日が軽いプラスまたは小負けで終わっている台**です。極端な大勝ち直後や、直近7日で高内容が複数回ある台は弱く、特に `prevG >= 4000 && highContentCount7 >= 3 && strongHighCount14 >= 2` は機械割93.61%まで落ちました。

特定日は平均的に成績を押し上げますが、特定日そのものを加点すると未来の営業意図に寄せすぎるため、最終ロジックでは`特定日`を点数項目に入れません。通常日・特定日で別ロジックを作るほどの安定差は見えなかったため、**全日共通ロジックのみ**を採用します。

## 5. 指標定義

| 指標名                   | 計算式                         | 使う履歴範囲    | 欠損・低G数の扱い                           | 未来情報を含まない理由   |
| --------------------- | --------------------------- | --------- | ----------------------------------- | ------------- |
| `historyDays`         | 同一台番の過去データ件数                | 同一台番過去全件  | 台番初登場から数える                          | 判定日前のみ        |
| `prevDiff`            | 直前営業データの差枚                  | 直近1件      | なければnull                            | 判定日前のみ        |
| `prevG`               | 直前営業データのG数                  | 直近1件      | なければnull                            | 判定日前のみ        |
| `diff7`               | 過去7件の差枚合計                   | 同一台番過去7件  | 足りない分は存在分のみ。ただし採用は`historyDays>=14` | 判定日前のみ        |
| `g7`                  | 過去7件のG数合計                   | 同一台番過去7件  | 同上                                  | 判定日前のみ        |
| `diff14`              | 過去14件の差枚合計                  | 同一台番過去14件 | 採用条件は14件以上必須                        | 判定日前のみ        |
| `rbRate7`             | `g7 / rb7`                  | 同一台番過去7件  | `rb7 == 0` はnull                    | 判定日前のみ        |
| `daysSinceHigh`       | 前回高内容からの同一台番営業データ数。前日高内容なら0 | 同一台番過去全件  | 過去に高内容なしはnull                       | 判定日前のみ        |
| `daysSinceStrongHigh` | 前回強高内容からの同一台番営業データ数         | 同一台番過去全件  | 過去になしはnull                          | 判定日前のみ        |
| `highContentCount7`   | 過去7件の高内容回数                  | 同一台番過去7件  | 存在分のみ                               | 判定日前のみ        |
| `strongHighCount14`   | 過去14件の強高内容回数                | 同一台番過去14件 | 存在分のみ                               | 判定日前のみ        |
| `weakHighCount7`      | 過去7件の準高内容回数                 | 同一台番過去7件  | 存在分のみ                               | 判定日前のみ        |
| `lossStreak`          | 直前から連続で`diff < 0`だった件数      | 同一台番過去全件  | 0可                                  | 判定日前のみ        |
| `rank`                | 同一実績日内のscore降順dense rank    | 当日の候補台全体  | `historyDays>=14`のみ母集団              | scoreは前日以前で作成 |
| `topGap`              | 自台score − 次に低い異なるscore      | 同一実績日内    | 下位scoreなしは0                         | scoreは前日以前で作成 |
| `dangerCount`         | 危険項目の該当数                    | 下記条件      | 0以上                                 | 判定日前のみ        |
| `boostCount`          | 強化項目の該当数                    | 下記条件      | 0以上                                 | 判定日前のみ        |

## 6. 強化条件・危険条件・見送り条件

### boostCount

```text
boostCount =
(prevDiff >= -600 && prevDiff <= 1000 ? 1 : 0)
+ (daysSinceHigh >= 5 && daysSinceHigh <= 21 ? 1 : 0)
+ (diff7 <= 1500 && g7 >= 8000 && highContentCount7 <= 1 ? 1 : 0)
+ (rbRate7 <= 446 ? 1 : 0)
+ (prevG < 3400 ? 1 : 0)
```

### dangerCount

```text
dangerCount =
(prevDiff >= 1200 ? 1 : 0)
+ (prevG >= 4800 ? 1 : 0)
+ (highContentCount7 >= 2 ? 1 : 0)
+ (daysSinceHigh == 0 ? 1 : 0)
+ (strongHighCount14 >= 2 ? 1 : 0)
+ (g7 > 27000 ? 1 : 0)
```

### 見送り条件

```text
historyDays >= 14 && prevG >= 4000 && highContentCount7 >= 3 && strongHighCount14 >= 2
```

この条件は18台、総G数50,020、差枚-9,583、平均差枚-532.4、機械割93.61%、勝率33.3%でした。
