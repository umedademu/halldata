## 結論

ワンダーランド南ヶ丘店の **ミスタージャグラー** は、深い凹み上げよりも、**前日または直近3日以内に高内容を見せた台をもう一度使うクセ** が最も強く出ました。特に、前日高内容・前日設定4以上推定率・直近の低稼働混在・直近高内容回数が重なる台が強いです。

一方で、**毎日1位を機械的に座るだけでは弱い** です。毎日1位はRB 1/327.8、合算1/150.1、機械割99.90%で、全体平均との差は小さく、実戦主軸には不十分でした。むしろ `score >= 58` 以上の絶対評価で拾い、`score >= 70` を最本命にする方が成績が安定します。

通常日・特定日の分離は行いません。特定日側は全体では少し良いものの、履歴条件の効き方が明確に別物とは言えず、履歴14日以上の特定日サンプルも11日分だけなので、専用ロジック化は過剰最適化寄りです。

## 高内容日の定義

ミスタージャグラーは、設定4以上を成功目標にし、評価優先順は **RB/REG確率 ＞ 合算確率 ＞ 設定推定率の分布 ＞ 機械割 ＞ 平均差枚** としました。これは添付プロンプトのミスタージャグラー特例に合わせています。

| ラベル  | 条件式                                                   |   |                  |
| ---- | ----------------------------------------------------- | - | ---------------- |
| 準高内容 | `G >= 3000 && ((combinedRate <= 150 && rbRate <= 360) |   | p4plus >= 0.35)` |
| 高内容  | `G >= 3500 && ((combinedRate <= 140 && rbRate <= 320) |   | p4plus >= 0.50)` |
| 強高内容 | `G >= 4000 && ((combinedRate <= 130 && rbRate <= 290) |   | p5plus >= 0.50)` |

設定推定率は、BIG・REGの各設定別確率から設定1〜6の尤度を出し、`p4plus = 設定4+5+6推定率`、`p5plus = 設定5+6推定率`、`p3minus = 設定1+2+3推定率` として扱います。ミスタージャグラーでは、設定4以上推定率を主指標、設定5以上推定率を強条件の補助指標として扱う指定に合わせました。
