## 2. 高内容日の定義

実戦前に使う点数には当日の結果を入れません。ただし、過去履歴の中で「前回高内容から何営業日か」を計算するために、過去日の高内容ラベルを使いました。

| ラベル  | 定義                                                               |   |                              |
| ---- | ---------------------------------------------------------------- | - | ---------------------------- |
| 準高内容 | `G数 >= 3500 && (((設定4以上推定率 >= 0.40) && RB確率 <= 360 && 合算 <= 150) |   | (RB確率 <= 320 && 合算 <= 145))` |
| 高内容  | `G数 >= 4500 && (((設定4以上推定率 >= 0.50) && RB確率 <= 335 && 合算 <= 145) |   | (RB確率 <= 300 && 合算 <= 140))` |
| 強高内容 | `G数 >= 5000 && (((設定5以上推定率 >= 0.40) && RB確率 <= 295 && 合算 <= 135) |   | (RB確率 <= 270 && 合算 <= 130))` |

マイジャグラーを含む機種は、Webアプリ用の段階的条件を期待RB基準で並べ、1/320、1/310、1/300、1/290、1/280を目安にする指定があるため、その方針で整理しています。

## 3. 見えたクセ

最も再現性があったのは、**4〜8連敗中で、直近14営業日の差枚角度が急に沈んでいる台を返す動き**です。特に `score >= 90` と組み合わせると、173件でRB 1/297.92、合算 1/137.98、平均差枚 +534.72枚、機械割 102.69% でした。前半・後半でもほぼ同じ成績で、過剰最適化の疑いは比較的低いです。

次に強かったのは、**特定日の同一機種内1位**です。特定日1位は77件でRB 1/300.88、合算 1/139.02、平均差枚 +496.10枚、機械割 102.56% でした。さらに `topGap >= 6 && boostCount >= 5` まで重なる特定日最強条件は21件でRB 1/269.68、合算 1/126.62、平均差枚 +1247.05枚、機械割 105.92% まで上がりました。ただし21件なので、これは通常採用にしてよいものの「少件数注意」の扱いです。

逆に、通常日に高めのscoreでも **2連勝後** は弱く、38件でRB 1/349.76、合算 1/154.44、平均差枚 -201.24枚、機械割 98.78% でした。これは見送り条件として採用します。

## 4. 検証したが弱かった仮説

## 12. 実戦での使い方

実戦では、まず **特定日か通常日か** を見ます。特定日なら `特定日最強_1位次点6強化5` を最優先、次に `特定日1位` を確認します。通常日・全日共通では、`90点以上＋4〜8連敗＋14日角度-60` を主軸にします。

ただし、通常日に `score >= 60 && winStreak >= 2` が出た台は見送りです。点数がそれなりに高くても、直近で出た後の台はこの店舗のマイジャグラーVでは弱く出ています。

この機種では、単純な毎日1位狙いよりも、**4〜8連敗＋14日急沈み＋90点以上** を全日共通の主軸にするのが最も現実的です。特定日は全日共通ロジックに加えて、日内順位と次点差を使った特定日専用条件を重ねるべきです。
