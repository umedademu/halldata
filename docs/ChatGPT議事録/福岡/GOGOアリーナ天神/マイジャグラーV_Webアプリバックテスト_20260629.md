## 実装メモ

- 100点ロジック名は `GOGOアリーナ天神_マイジャグラーV_全日共通_100点ロジック`。
- 角度は差枚をG数で割った1000Gあたりの値として扱う。
- `rbRate3` と `rbRate5` の本物感補正は、回答内の該当一覧に一致するよう重複加点せず、3日条件が成立した場合は+8、成立しない場合のみ5日条件で+5とした。
- 近隣判定は、今回の回答値に合わせて同一機種設置順の左右1台を使った。
- `自由MAX_短期急沈みローテ`、`自由MAX_深沈み強高履歴`、`90点以上かつ1位` を通常採用として有効化した。
- `見送り_前日強高処遇済み` と `14日大幅プラス警告` は、点数が残っても危険確認できるラベルとして表示する。
- `70点以上_青参考` と `80点以上_黄参考` はWeb実測で回答値と完全一致しないため有効化しない。
