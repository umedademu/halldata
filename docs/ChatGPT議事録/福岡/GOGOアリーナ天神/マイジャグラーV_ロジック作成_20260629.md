# 3. マイジャグラーVの設定推定率

設定別ボーナス確率：
| 設定 | BIG確率 | REG確率 | 合成確率 | 機械割 |
|---|---:|---:|---:|---:|
| 1 | 1/273.1 | 1/409.6 | 1/163.8 | 97.70% |
| 2 | 1/270.8 | 1/385.5 | 1/159.1 | 98.60% |
| 3 | 1/266.4 | 1/336.1 | 1/148.6 | 100.90% |
| 4 | 1/254.0 | 1/290.0 | 1/135.4 | 104.00% |
| 5 | 1/240.1 | 1/268.6 | 1/126.8 | 106.90% |
| 6 | 1/229.1 | 1/229.1 | 1/114.6 | 111.30% |

各台日について、総G数をG、BIG回数をB、REG回数をRとする。
各設定sについて、pB_s、pR_sを使い、対数尤度を以下で計算する。

logWeight_s =
B * log(pB_s) + (G - B) * log(1 - pB_s)
+
R * log(pR_s) + (G - R) * log(1 - pR_s)

最大logWeightを引いてexpに戻し、設定1〜6で正規化する。
設定4以上推定率 = p4 + p5 + p6
設定5以上推定率 = p5 + p6
設定3以下推定率 = p1 + p2 + p3

注意：
- 当日実績の設定推定率は評価指標としてだけ使う。
- 狙い度の説明変数として未来の当日実績は使わない。
- 履歴内の過去日については、その日が終わった後に分かっているB/R/Gから高内容ラベルを作るため、未来情報ではない。
