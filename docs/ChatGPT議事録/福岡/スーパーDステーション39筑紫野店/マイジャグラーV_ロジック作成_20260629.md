## 結論

スーパーDステーション39筑紫野店の**マイジャグラーV**は、単純な「凹み上げ」よりも、**直近7日の急角度マイナス＋露出しすぎていない台**、または**点数1位かつ危険条件なし**が強いです。

最優先は次の順です。

1. **紫急角度低露出_最優先**
   `historyDays >= 21 && angle7 <= -150 && games7 <= 30000 && dangerCount == 0`
   RB **1/277.82**、合算 **1/132.03**、平均差枚 **+676.47枚**、機械割 **103.92%**

2. **緑1位_危険0**
   `historyDays >= 21 && rank == 1 && dangerCount == 0`
   RB **1/292.45**、合算 **1/132.82**、平均差枚 **+748.47枚**、機械割 **104.57%**

3. **黄本命_94点危険0**
   `historyDays >= 21 && score >= 94 && dangerCount == 0`
   RB **1/304.40**、合算 **1/133.67**、平均差枚 **+761.11枚**、機械割 **104.86%**

4. 広く拾うなら **青入口_80点危険0**
   `historyDays >= 21 && score >= 80 && dangerCount == 0`
   RB **1/318.42**、合算 **1/140.52**、平均差枚 **+399.30枚**、機械割 **102.69%**

最終目的は分析レポートではなく、CodexがWebアプリへ迷わず実装できる「実装用の正本」を作ることなので、途中仮説ではなく、下の**実装用正本**と**Codex貼り付け用 実装依頼**を実装対象にしてください。

## 2. 高内容日の定義

設定列は使わず、G数・BB・RB・合算・差枚から次の3段階を作りました。

| ラベル  | 条件式                               |   |                                                         |   |                                                         |
| ---- | --------------------------------- | - | ------------------------------------------------------- | - | ------------------------------------------------------- |
| 準高内容 | `games >= 4000 && (p4plus >= 0.40 |   | (rb_rate <= 320 && combined_rate <= 145)                |   | (rb_rate <= 300 && combined_rate <= 155))`              |
| 高内容  | `games >= 5000 && (p4plus >= 0.55 |   | (rb_rate <= 300 && combined_rate <= 140)                |   | (rb_rate <= 280 && combined_rate <= 150 && diff >= 0))` |
| 強高内容 | `games >= 6000 && (p5plus >= 0.55 |   | (rb_rate <= 270 && combined_rate <= 130 && diff >= 0))` |   |                                                         |

設定推定率は、マイジャグラーVの設定別BB/RB確率を使い、BBとRBの二項尤度を対数計算して正規化しました。最重要指標は `p4plus = p4 + p5 + p6`、補助指標は `p5plus = p5 + p6`、失敗側は `p3minus = p1 + p2 + p3` です。

## 3. 見えたクセ

一番強かったのは、**直近7日で急角度に沈み、かつ7日G数が多すぎない台**です。単純な累計凹みではなく、`angle7 <= -150` と `games7 <= 30000` を同時に満たすと、RB **1/277.82** まで上がりました。

次に強いのは、100点ロジックの**日別1位**です。`rank == 1 && dangerCount == 0` は選択34台で、RB **1/292.45**、合算 **1/132.82**、平均差枚 **+748.47枚**でした。日別順位は、全台を毎日同じ土俵で比較する用途に向いています。

逆に、**長期で深く沈みすぎた台・露出しすぎた台は弱い**です。`diff21 <= -8000`、`games21 >= 110000`、`games14 >= 70000` はいずれもRBが重く、危険条件に入れました。
