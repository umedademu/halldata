実装計算：
- G = 総G数、B = BB回数、R = RB回数。
- 各設定sについて、BIG確率pB_s、REG確率pR_sを使う。
- logWeight_s = B*log(pB_s) + (G-B)*log(1-pB_s) + R*log(pR_s) + (G-R)*log(1-pR_s)
- 組み合わせ項は同一G,B,R内では全設定で共通なので、正規化後の設定比率には影響しない。入れても入れなくても同じ比率になる。
- maxLogを引いてexpし、合計1になるように正規化する。
- p56 = p5 + p6
- p4low = p1 + p2 + p3 + p4
- ネオアイムではp56をヒット率代理指標、p4lowを失敗側指標とする。
- 設定列は実戦用説明変数に使わない。
