## 2. 高内容日の定義

ネオアイムなので、設定5・6級に座れたかを成功寄りに扱いました。設定5・6推定率は、G数・BB・RBから設定1〜6それぞれのBB/RB出現尤度を出し、正規化して計算しています。これは、指定されていたネオアイムの設定別BB/REG確率と、設定5・6推定率の計算方法に沿ったものです。

実戦用の高内容履歴ラベルは以下です。

| ラベル     | 定義                                                |
| ------- | ------------------------------------------------- |
| 高内容     | G数5,000以上、かつ設定5・6推定率50%以上、またはRB1/285以下かつ合成1/140以下 |
| 強高内容    | G数5,500以上、設定5・6推定率70%以上、合成1/135以下                 |
| 不発高内容   | G数4,500以上、設定5・6推定率50%以上、差枚+800枚未満                 |
| 処遇済み高内容 | G数4,500以上、設定5・6推定率50%以上、差枚+1,200枚以上               |

最終評価の優先順は、**設定5・6推定率 ＞ RB/REG確率 ＞ 合算確率 ＞ 機械割**です。
機械割が高くても、56推定率やRBが弱い条件は本命扱いしていません。

## 3. 設定師のクセの仮説

強く見えた順です。

### 1位：通常日は「前日しっかり回されて、合成が本物で、周辺にも高内容がある台」が強い

通常日の本命条件は、

```text
通常日
前日G数 >= 8,000
前日合成 <= 1/120
近隣4台の前日高内容台数 >= 2
```

この条件で、RB1/284.1、合成1/136.4、平均差枚+504.4枚、平均56推定率41.9%まで上がりました。

これは、単純なヘコミ返しではなく、**見える場所・回される場所・周辺と一緒に見せる場所を続けて使うクセ**が強いです。

### 2位：特定日は通常日とまったく違い、「前日RBが極端に強い＋周辺の直近高内容密度」が効く

特定日の本命条件は、

```text
特定日
前日RB <= 1/250
近隣4台の直近7日高内容合計 >= 7
直近7日差枚 > -2,500
```

この条件で、RB1/289.7、合成1/138.6、平均差枚+572.5枚、平均56推定率39.5%でした。

通常日で強い「前日高G＋前日本物感＋隣前日高内容」は、特定日ではRB1/335.3、平均56推定率25.2%まで落ちます。
そのため、**通常日専用ロジックと特定日専用ロジックは分けるべき**です。

### 3位：日ごとの1位狙いより、絶対条件のほうが強い

100点ロジックの日別1位だけを毎日打つと、RB1/336.7、平均56推定率25.3%でベース以下でした。
一方、点数80点以上＋強化2個＋危険1個以下では、RB1/319.0、合成1/144.9、平均差枚+239.1枚まで改善します。

つまり、この店のネオアイムは、**ランキング1位を毎日座る機種ではなく、条件が出た日だけ拾う機種**です。

## 12. 実戦での使い方

### 毎日の順位付けに使うもの

```text
全日共通100点ロジック
```

ただし、1位だから座るのではなく、70点以上・80点以上・90点以上を足切りにし、強化条件と危険条件を必ず見るべきです。

### 条件が出た日だけ打つ本命ルール

通常日はこれを最優先。

```text
通常日
前日G >= 8,000
前日合成 <= 1/120
近隣4台の前日高内容 >= 2
```

特定日はこれを最優先。

```text
特定日
前日RB <= 1/250
近隣4台の直近7日高内容合計 >= 7
直近7日差枚 > -2,500
```

### Webアプリの条件列で確認する補助ルール

```text
全日310 → 全日300 → 全日290
通常310 → 通常300 → 通常290
特定310 → 特定300 → 特定290
```

1/280・1/270は表示してもよいですが、件数不足なので「参考」「過剰最適化注意」のラベルを付けるべきです。

## 13. 最終結論

この機種では、**自由度MAX条件を主軸**にするのが最も現実的です。

優先順位は以下です。

```text
1. 自由度MAX条件
   - 通常日は 通常 本命290
   - 特定日は 特定 本命290 または 特定 弱本命300

2. Webアプリ用の段階的採用条件
   - 条件列で強弱を見せる
   - 1/280・1/270は参考扱い

3. 100点満点ロジック
   - 毎日の土台スコア
   - 1位狙いではなく、足切りと危険除外に使う
```

通常日と特定日ではクセが明確に違うため、
Webアプリでは、

```text
機種別：全日共通ロジック
通常日：通常日専用ロジック
特定日：特定日専用ロジック
```

として分けるべきです。
