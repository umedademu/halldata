## 2. 高内容日の定義

ネオアイムなので、評価は機械割よりも `設定5・6推定率` を最重要にしました。設定5と設定6は分けず、設定5・6級に座れたかを成功寄り、設定4以下は失敗寄りとして扱っています。

| 区分                | 定義                                         |
| ----------------- | ------------------------------------------ |
| 準高内容 `semiHigh`   | `G数 >= 3000 && p56 >= 0.30 && 合算 <= 1/155` |
| 高内容 `high`        | `G数 >= 3500 && p56 >= 0.50`                |
| 強高内容 `strongHigh` | `G数 >= 5000 && p56 >= 0.70`                |
| p56               | BB/RB/G数からネオアイム設定1〜6の対数尤度を計算し、設定5+6の正規化後確率 |
| p4down            | 設定1〜4の推定率合計                                |

## 3. 見えたクセ

一番強かったのは、**直近7日でボーナス内容がかなり悪く、かつ14日単位でも沈んでいる台を返す傾向**です。`combined7 >= 180` と `diff14 <= -1000/-2000/-4000` の段階で、RBが `1/302.7 → 1/297.4 → 1/287.8` と軽くなりました。

次に強かったのは、**28日間高内容がなく、ただし準高内容が3〜7日前にある台**です。これは「完全放置」ではなく、一度軽く触った台をもう一度本命寄りに使う形に見えます。RB `1/278.4`、合算 `1/134.8`、平均差枚 `+454枚` でした。

逆に、**直近7日で合算が良すぎて差枚も浮いている台**は明確に弱く、`combined7 <= 130 && diff7 >= 1000` はRB `1/433.4`、合算 `1/165.3`、平均差枚 `-133.9枚` でした。これは処遇完了の見送り条件として使えます。

## 4. 弱かった仮説

単純な「長く高内容がないほど強い」は弱いです。`highCount28 == 0` 単体は強いですが、準高内容の近さがないと放置台も混ざります。

単純な「前日凹み」も弱めです。3日・7日・14日の沈みと、7日合算の悪さが重なって初めて実用的でした。

特定日そのものの加点は採用しません。イベント日のほうが同条件で強く出る傾向はありましたが、最終点数には `特定日だから加点` を入れません。
