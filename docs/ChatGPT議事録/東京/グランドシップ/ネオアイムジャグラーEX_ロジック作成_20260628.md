## 2. 高内容日の定義

ネオアイムなので、評価の中心は **設定5・6推定率** です。

履歴特徴として使う「高内容」は以下で定義しました。

| ラベル    | 定義                             |
| ------ | ------------------------------ |
| 高内容50  | 当日G数2,500G以上、かつ設定5・6推定率50%以上   |
| 高内容70  | 当日G数2,500G以上、かつ設定5・6推定率70%以上   |
| 本物感あり  | 設定5・6推定率30%以上、またはRB・合算が一定以上強い日 |
| 不発高内容  | 高内容50以上だが差枚+500枚以下             |
| BB寄り出玉 | 差枚+1,000枚以上だが設定5・6推定率30%未満     |

全体ベースはかなり辛めです。

| 条件         |    台数 |      RB |      合算 | 平均差枚 |    機械割 |  平均56 | 中央値56 | 56率50%以上 |
| ---------- | ----: | ------: | ------: | ---: | -----: | ----: | ----: | -------: |
| 全体 hist21+ | 4,345 | 1/347.7 | 1/152.1 | -21枚 | 99.80% | 26.2% | 21.8% |    11.9% |

つまり、何も考えずに座ると設定5・6級に座れている可能性は低く、狙い台ロジックで **RB1/310前後まで引き上げられるか** が現実的な目標です。

「直近でREGが良かった台」より、**最近ボーナスが弱く見えていて、客目線で触りにくい台** の方が強いです。

### 4位：前日高内容の据え置きは弱い

前日高内容をそのまま据えるより、**高内容がしばらく来ていない台を返す** 方が強いです。

### 5位：通常日とイベント日でクセが明確に違う

共通スコアはイベント日にかなり効き、通常日は効きが弱いです。

イベント日は同じ履歴条件でも返しが強いです。これは「特定日だから加点」ではなく、**イベント日の母集団で同じ履歴要素がより効いた** という扱いにします。

## 13. 実戦での使い方

### 毎日の順位付け

まずは **全日共通スコア** を見る。
目安は以下です。

|               点数 | 扱い    |
| ---------------: | ----- |
|            85点以上 | 広め候補  |
|            90点以上 | 本命候補  |
| 90点以上＋1位＋次点差12以上 | 強候補   |
|   90点以上＋21日高内容なし | 最本命候補 |
|            80点未満 | 原則弱い  |

### 条件が出た日だけ打つ本命ルール

優先順位はこれです。

1. **イベント日＋EV沈み超本命**
   4連敗以上、7日RB1/350以上、21日高内容なし。出たら最優先。

2. **イベント日＋EV95点以上**
   広めに打てるイベント本命。

3. **全日共通：1位＋次点差12以上**
   日付種別を問わず、差が明確な日だけ打つ。

4. **全日共通：4連敗＋21日高内容なし＋3位以内**
   件数は少ないが、RB・合算が明確に強い。

5. **通常日：4連敗以上だけでは弱い**
   通常日は、他に本命条件がなければ見送り寄り。

### Webアプリ条件列で確認する補助ルール

* `機種別`：全日共通スコアを表示。
* `通常日`：通常日専用スコアを表示。ただし強く打つより見送り判断。
* `特定日`：イベント日専用スコアを表示。ここが強ければ本命扱い。
* `条件`：RB段階ラベルを表示。

  * 85点以上
  * 1位＋差12
  * 4連敗＋21日高なし
  * EV95点以上
  * EV沈み超本命
  * 前日大勝危険
  * BB寄り出玉危険

## 14. 最終結論

この店舗のネオアイムは、**ヘコみ返済・連敗返し・イベント日の沈み台返し** が主軸です。

| 判断         | 結論                             |
| ---------- | ------------------------------ |
| 100点満点ロジック | 毎日の順位付けの土台として使うべき              |
| 段階的採用条件    | Webアプリ表示用に必須。特にRB段階で表示する       |
| 自由度MAX条件   | 実戦本命として最優先。イベント沈み条件は点数より優先     |
| 通常日        | 無理に打たない。4連敗以上でもRB1/316程度       |
| イベント日      | 明確に狙える。EV95点以上、EV沈み超本命が強い      |
| 最重要条件      | 4連敗以上、7日RB弱、21日高内容なし、1位次点差12以上 |
| 見送り        | 前日大勝、BB寄り出玉、近隣高内容後、履歴不足        |

実戦確認順は、

**履歴不足・危険除外 → 全日共通85点以上 → 1位次点差12以上 → イベント日ならEV95点以上 → EV沈み超本命があれば最優先**

です。
