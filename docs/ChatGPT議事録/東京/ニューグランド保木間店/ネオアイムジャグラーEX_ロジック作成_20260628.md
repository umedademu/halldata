## 2. 高内容日の定義

ネオアイムジャグラーEXは、今回の目的上、**設定5・6級だけを成功扱い**、設定4以下は失敗扱いにしました。指示書でも、ネオアイムでは設定5・6級に座れた割合を最重要にし、設定4以下は失敗扱いとする指定があります。

今回の高内容判定は以下です。

| 判定       | 定義                                    |
| -------- | ------------------------------------- |
| 設定5・6推定率 | G数、BB、RBから設定1〜6の尤度を計算し、設定5＋設定6の推定率を合算 |
| 高内容日     | G数3,000G以上、かつ設定5・6推定率50%以上            |
| 強高内容日    | G数3,000G以上、かつ設定5・6推定率70%以上            |
| 参考       | RB、合算、差枚、機械割は必ず併記                     |
| 最終評価優先順  | 設定5・6推定率 ＞ RB/REG確率 ＞ 合算確率 ＞ 機械割      |

設定推定率は、指示書の通り、BIG確率とREG確率を別々に使う二項尤度で計算しました。各設定の重みを正規化し、設定5＋設定6を「設定5・6推定率」としています。

なお、CSVには「設定」列がありますが、これは最終ロジックの説明変数には使っていません。検証上の参考値として確認しただけです。最終ロジックでは、当日前に分かる **差枚・G数・BB・RB・合算・履歴上の推定p56** だけを使います。

最も強かったのは、**直近5日の設定5・6推定率平均が低い台**、つまり最近ずっと内容が弱く見えていた台に、さらに直近3日で差枚マイナスが重なったパターンです。

4連敗以上で、直近3日差枚が-2,000枚以下まで沈むとかなり強くなります。

## 7. Webアプリ用の段階的採用条件

ネオアイムなので、通常機種の機械割段階ではなく、期待RB段階で整理しています。指示書でも、ネオアイムは期待RB 1/310以下、1/300以下、1/290以下、1/280以下、1/270以下の段階で整理する指定があります。

ただし、このCSVでは **RB 1/280以下・1/270以下を安定して満たす再現性条件は見つかりませんでした。**
無理に作ると過剰最適化になるため、Webアプリには **RB310・RB300・RB290の3段階** を実装し、RB280/RB270は「未採用」とするのが安全です。

## 13. 最終結論

この機種では、**100点満点ロジックを主軸にしすぎない方がよい** です。

| 使い方              | 主軸にするべきもの           |
| ---------------- | ------------------- |
| 毎日の候補順位を見る       | 100点満点ロジック          |
| 実際に座るか決める        | 自由度MAX条件            |
| Webアプリで価値を段階表示する | RB310/RB300/RB290条件 |
| 見送り判断            | 危険条件0かどうか           |

最終優先順位は以下です。

1. **自由最強RB条件**：直近5日p56平均≤15%＋直近3日≤-2,000＋4連敗以上
2. **自由バランス条件**：直近3日≤-2,000＋4連敗以上＋直近5日RB>1/450
3. **Web条件：広めRB310以上**
4. **100点ロジック85点以上＋危険0**
5. **ランキング1位だけ、次点差だけは非推奨**
