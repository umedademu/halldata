# 12. 実戦での使い方

毎日の順位付けには、まず `機種別` 列の全日共通スコアを使います。ただし、それだけで座るより、`通常日` または `特定日` の専用列を重ねる方が強いです。

条件が出た日だけ打つ本命ルールは、**特定21低G＋14合成悪**、**特定14沈み＋21低G**です。この2つは自由探索で最も強く、特定日に出た場合は点数順位より優先してよいです。

Webアプリの条件列では、広めに拾うなら `75点以上`、本命は `専用1位`、強条件は `特定日専用1位`、最本命は `特定日専用1位＋次点差2以上` と表示するのが分かりやすいです。

見送りは、通常日の処遇完了台、危険条件2個以上、履歴不足、強化条件が少ない高スコア台です。

# 13. 最終結論

この機種では、**100点満点ロジックを土台にしつつ、実戦主軸は通常日/特定日専用ロジックと自由度MAX条件に置くべき**です。

優先順は以下です。

1. **自由度MAX条件**：特定21低G＋14合成悪、特定14沈み＋21低G
2. **専用ロジック**：通常日なら通常日専用1位、特定日なら特定日専用1位
3. **全日共通ロジック**：機種別列で全台の土台評価
4. **次点差**：1位＋次点差2点以上なら信頼度アップ
5. **危険条件**：通常日処遇完了、危険2個以上は見送り寄り

したがって、Webアプリでは、全日共通ロジックを `機種別` 列、通常日専用を `通常日` 列、特定日専用を `特定日` 列に表示する実装が最も現実的です。
