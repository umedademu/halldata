## 2. 高内容日の定義

ネオアイムジャグラーEXは、平均差枚や機械割よりも、**設定5・6級に座れたか**を最重要にしました。今回のプロンプトでも、ネオアイムは設定5・6級だけを成功、設定4以下を失敗扱いにする指定があるためです。

各台日について、G数・BB・RBから設定1〜6の尤度を計算し、以下を算出しました。

| P4以下  | 設定1〜4推定率                       |

## 13. 最終結論

この機種では、**100点満点ロジックだけを主軸にするべきではありません**。
100点ロジックは毎日の候補整理には有効ですが、ネオアイムの成功基準であるP56を大きく引き上げるには不足します。

最も現実的なのは以下です。

| 用途        | 主軸                |
| --------- | ----------------- |
| 毎日の順位付け   | 100点満点ロジック        |
| 実戦で座る本命判断 | 自由度MAX条件          |
| Webアプリ条件列 | RB段階の採用条件         |
| 最優先条件     | 自由A＋危険0、自由A/F＋危険0 |
| 専用ロジック分岐  | 通常日・特定日で分けない      |

実戦確認順は、
**自由A/F系 → 危険0 → Web段階条件 → 100点順位 → 次点差2以上の有無**
が最もよいです。

この条件は149台でRB 1/316.7、合算1/146.0、平均差枚+80.8枚、平均p56 31.3%です。RBの軽さだけなら最上位ではありませんが、台数が多く、実戦で拾いやすい補助条件です。

### 強そうなクセ3：イベント日は同じ条件が強く出やすいが、専用ロジック化は危険

イベント日は通常日より強く見えます。たとえば毎日1位は、通常日ではRB 1/321.8・平均p56 29.7%ですが、特定日ではRB 1/301.9・平均p56 36.2%でした。

ただし、イベント日だけで選ぶと件数が少なく、日付種別そのものを加点に入れるのは禁止条件です。通常日・イベント日で履歴パターン自体が明確に別物というより、「同じ強履歴条件がイベント日に強く出やすい」程度でした。したがって、通常日専用・イベント日専用ロジックは今回は作らず、全日共通ロジックだけを採用します。

### 強そうなクセ4：近隣台要素は補助としては使える

近隣台の直近強内容が多すぎない、または周辺に見せ場があって自台だけ取り残されている、という条件は一部で効きました。ただし単独で主軸にするほどではありません。100点ロジックでは小さめの加点に留めるべきです。

## 12. 実戦での使い方

### 毎日の順位付けに使うもの

まずは100点満点ロジックの順位を見ます。特に1位を中心に見て、2位以下は強い自由条件が重なった場合だけ候補にします。

### 条件が出た日だけ打つ本命ルール

最優先は以下です。

```text
狙い度1位
かつ 直近3日合成1/135以下
かつ 直近5日RB1/290以下
```

## 2. 高内容日の定義

ネオアイムジャグラーEXなので、成功判定は**設定5・6級に座れたか**を最重視しました。設定5・6推定率は、指定されたBIG確率・REG確率を使い、各台のG数・BB・RBから設定1〜6の尤度を出し、設定5+設定6の合計を算出しています。

今回の分析上の定義は以下です。

| 定義      | 条件                                             |
| ------- | ---------------------------------------------- |
| 高内容56候補 | 当日G数3000G以上、かつ設定5・6推定率50%以上                    |
| 強高内容    | 当日G数3000G以上、設定5・6推定率70%以上                      |
| 本物感あり   | 当日G数3000G以上、設定5・6推定率50%以上、RB 1/310以下、合算1/145以下 |
| 低信頼     | G数3000G未満、またはRB/合算が極端に荒れている台                   |

ネオアイムではREG確率を最重要にしていますが、RB単独ではなく、BB/RB別の設定推定率、合算、G数、差枚も併記して判断しました。段階的条件も、期待RBだけでなく設定5・6推定率と設定4以下推定率を併記する指定に合わせています。

## 3. 設定師のクセの仮説

強く見えた順です。

**1位：中程度の沈み + 返済未完了を使う傾向**
深すぎる凹みではなく、直近3〜5日でほどよく沈み、まだ返し切っていない台が強めでした。特に「直近5日 -2000〜-700枚、直近3日 -1500〜-500枚、近隣に見せ場あり」は、RB 1/307.5、合算1/140.4、平均差枚+364枚でした。

**2位：前回高内容から2〜4日、または7〜12日の再投入ゾーン**
前回の高内容直後の単純据え置きより、少し間隔を空けた再投入が強いです。2〜4日後は特に短期ローテ、7〜12日後は連敗・沈みと重なる時に強くなりました。

**3位：前日が合算だけ良く、RBが弱めだった台の翌日補正**
前日合算1/135〜1/150、前日RB1/390〜1/500のように、BB寄りで見えた台が翌日にRB良化するパターンがありました。これは「出たから終わり」ではなく「内容的には未処遇」と見てよさそうです。

**4位：直近7日で高内容2回、直近14日で高内容3回前後の台**
高内容がゼロの完全放置台より、直近である程度触られている台が強いです。ただし、直近7日で高内容3回以上はやや危険で、処遇完了寄りに見ます。

**5位：周辺に見せ場がある中で取り残されている台**
近隣4台の前日見せ場が2台以上ある条件は、単独では劇的ではないものの、沈み条件と重なると強化材料になりました。

## 12. 実戦での使い方

毎日の順位付けに使うものは、**100点満点ロジックの日別1位**です。毎日1位はRB 1/304.7、合算1/143.4、平均p56 34.74%まで改善しました。

## 13. 最終結論

この機種では、**100点満点ロジックを毎日の順位付けの主軸**にするのが最も現実的です。
ただし、実戦で最優先すべきなのは、100点ロジック単体ではなく、**自由度MAX条件A/D/Cが出た台**です。

最終的な優先順位は以下です。

1. **自由A・自由D・自由Cが出ている台**
2. **日別1位 + 80点以上 + 危険0**
3. **日別1位 + 次点差3以上**
4. **85点以上**
5. **80点以上**
6. **70点台は補欠、70点未満は原則見送り**

通常日専用・イベント日専用ロジックは作りません。
理由は、特定日が24日しかなく、専用ロジックにすると件数不足と過剰最適化が強くなるためです。全日共通ロジックを`機種別`列に表示し、`通常日`・`特定日`列は今回は空欄または「専用ロジックなし」とするのが安全です。
