## 2. 高内容日の定義

ネオアイムは、機械割よりも **設定5・6級に座れたか** を最重要にしました。

各台について、G数を `G`、BIGを `B`、REGを `R` とし、設定別BIG確率・REG確率から設定1〜6の尤度を計算しました。最終指標は次の通りです。

| 指標       | 定義                        |
| -------- | ------------------------- |
| 設定5・6推定率 | 設定5推定率 + 設定6推定率           |
| 設定4以下推定率 | 設定1〜4推定率の合計               |
| 高内容日     | G数2,500G以上かつ設定5・6推定率50%以上 |
| 強高内容日    | G数3,000G以上かつ設定5・6推定率70%以上 |
| 評価優先順    | RB/REG確率 ＞ 合算確率 ＞ 機械割     |

## 12. 実戦での使い方

### 毎日の順位付けに使うもの

`ニュークラウン綾瀬店_ネオアイムEX_全日共通_v1` の100点スコアを使います。

## 13. 最終結論

この機種では、**100点満点ロジック単独を主軸にするべきではありません**。

最も現実的な使い方は次です。

1. **100点満点ロジック**：毎日の候補順位を作る土台
2. **自由度MAX条件**：実戦で座るかどうかの最優先判断
3. **Webアプリ用段階条件**：RB310〜RB270で座る価値の強弱を表示
4. **危険条件**：高得点台を消すためのフィルター

主軸にするべきなのは、**自由度MAX条件**です。特に `自由最本命_中凹み不発7G` は、RB1/286.61、合算1/143.82、平均56率39.01%で、今回のデータでは最も実戦向きです。
