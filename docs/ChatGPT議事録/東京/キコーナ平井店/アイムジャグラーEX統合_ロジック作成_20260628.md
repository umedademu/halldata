## 2. 高内容日の定義

今回はユーザー指定により、Sアイムとネオアイムを統合します。
ただし、評価軸はネオアイム特例に寄せ、**設定5・6級に座れたか**を重視します。ネオアイムでは設定5・6級を成功、設定4以下を失敗として扱う指示があるためです。

設定推定は、BIG回数とREG回数を設定別確率で尤度化し、設定5＋設定6の推定率を `設定5・6推定率` として計算する方式です。

### 高内容日判定

実戦用ロジックの説明変数には使いませんが、検証ラベルとして以下を使いました。

```text
高内容日 =
  G数2500以上 かつ 設定5・6推定率50%以上 かつ RB 1/330以下 かつ 合算1/145以下
または
  G数4000以上 かつ RB 1/300以下 かつ 合算1/140以下
または
  G数5000以上 かつ 設定5・6推定率65%以上
```

評価優先度は、ジャグラー系として **RB/REG確率 ＞ 合成確率 ＞ 機械割** としました。AタイプではRBと合算を重視するよう指定されています。

## 13. 最終結論

この機種では、**100点満点ロジックを主軸にしすぎない方が良い**です。

| 判断          | 結論                    |
| ----------- | --------------------- |
| 100点満点ロジック  | 毎日の順位付け・予備選別用         |
| 段階的採用条件     | Webアプリ表示用。座る価値の強弱を見せる |
| 自由度MAX条件    | 実戦主軸。最も優先すべき          |
| 次点差         | 不採用                   |
| 通常日/イベント日専用 | 作らない。特定日サンプルなし        |
| Sアイム/ネオアイム  | 分けない。同一のアイムEX系として扱う   |

実戦では、まず自由度MAX条件を確認し、該当台があればそれを優先。
該当台がない日は100点ロジックの上位を見ますが、90点以上でも強化条件が弱ければ見送りです。

## 12. 実戦での使い方

毎日の順位付けには、100点満点スコアを使います。ただし、スコア1位を無条件で座るのは弱いです。

条件が出た日だけ打つ本命ルールは、次の順番です。

1. **RB最軽**：21日差枚-7,000〜-3,000＋高内容後14〜27日＋7日G 5,000〜8,000＋14日G 7,000〜25,000
2. **7日急沈み**：95点以上＋7日角度-0.20以下＋高内容後14〜27日＋14日G 7,000〜25,000
3. **4連14-28**：95点以上＋4連敗以上＋高内容後14〜27日＋14日G 7,000〜25,000
4. **未返14-28**：95点以上＋高内容後14〜27日＋14日G 7,000〜25,000＋前回高内容後差枚-3,000以下

Webアプリの条件列では、点数だけでなく「未返14-28」「7日急沈み」「RB最軽」のようなラベルを見て判断するのが良いです。

## 13. 最終結論

この機種では、**100点満点ロジック単独を主軸にしない方がよい**です。スコアは候補抽出には使えますが、毎日1位や90点以上だけではRB・機械割が足りません。

最も現実的なのは、以下の運用です。

| 優先順位 | 使うもの                  | 理由                  |
| ---: | --------------------- | ------------------- |
|    1 | 自由度MAXのRB最軽条件         | RB 1/294.0で最もアイムらしい |
|    2 | Web段階条件の7日急沈み・4連14-28 | 合算と機械割のバランスが良い      |
|    3 | 100点満点ロジック            | 毎日の候補順位付け用          |
|    4 | 次点差                   | 12点以上のみ参考。主軸にはしない   |

実戦では、**RB最軽 or 7日急沈み or 4連14-28が出ていて、かつ前日高内容・前日大出し・直近7日高内容ありを避ける**のが最も安全です。

## 12. 実戦での使い方

### 毎日の順位付けに使うもの

まずは100点満点ロジックで全台を並べます。
ただし、毎日1位を無条件で打つより、**80点以上、できれば90点以上**を優先します。

### 条件が出た日だけ打つ本命ルール

優先順位は次の順です。

1. **RB欠損8連敗**
2. **14急沈み未処遇**
3. **14急沈み見せ場なし**
4. **7日＋14日急沈み**
5. **90点以上**
6. **80点以上＋危険条件0〜1個**

### Webアプリ条件列で見る補助ルール

`80点以上` は広め、`85点以上` は弱本命、`90点以上` は本命。
`14急沈み未処遇` と `RB欠損8連敗` は点数より優先できる自由条件として表示します。

### 見送り

以下は高スコアでも慎重に見送ります。

* 前日高内容
* 直近7日差枚+1,000枚以上
* 直近14日差枚+1,500枚以上
* 直近7日見せ場あり
* 危険条件2個以上
* 履歴7日未満

## 13. 最終結論

この機種では、**100点満点ロジックだけを主軸にするより、自由度MAX条件を上位に置いた方が実戦向き**です。

最終方針は以下です。

| 判断          | 結論                                   |
| ----------- | ------------------------------------ |
| 100点満点ロジック  | 毎日の順位付け用として採用                        |
| 段階的採用条件     | Webアプリの条件列表示として採用                    |
| 自由度MAX条件    | 実戦の本命判断として最優先                        |
| 通常日専用ロジック   | 作らない                                 |
| イベント日専用ロジック | 作らない                                 |
| 理由          | 特定日列がすべて `いいえ` のため、通常日・特定日のクセ比較ができない |

実戦では、**自由MAX条件 → 90点以上 → 80点以上 → 次点差補助 → 危険条件確認**の順で見てください。
