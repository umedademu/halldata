## 2. 高内容日の定義

ネオアイムの特例に従い、成功判定は**設定5・6級に座れたか**を主軸にしました。設定4以下は今回の狙い台ロジックでは失敗寄りとして扱います。

各台日のG数、BB、RBから、指示されたBIG/REGの二項分布尤度で設定1〜6の推定率を計算し、以下を使いました。

| 指標       | 定義                        |
| -------- | ------------------------- |
| 設定5・6推定率 | 設定5推定率 + 設定6推定率           |
| 設定4以下推定率 | 設定1〜4推定率の合計               |
| 高内容      | G数3,000G以上かつ設定5・6推定率50%以上 |
| 強高内容     | G数3,000G以上かつ設定5・6推定率70%以上 |
| 評価優先度    | RB/REG確率 ＞ 合算確率 ＞ 機械割     |

全台ベースでは、21日履歴後の3,502台日で、RBは**1/327**、合算は**1/148**、平均設定5・6推定率は**28.9%**、設定5・6推定率50%以上の割合は**15.9%**でした。これを基準に、各条件がどれだけ上振れするかを見ています。

## 3. 設定師のクセの仮説

強く見えた順です。

**1位：前日〜直近2日の深い凹み返し**
最も分かりやすく効いていました。前日-1,500枚以下だけで、RB**1/309**、平均差枚**+146枚**、設定5・6推定率50%以上**23.6%**。さらに「前日-1,500枚以下＋直近2日-1,000枚以下」まで重ねると、RB**1/303**、合算**1/143**、平均差枚**+190枚**まで上がりました。

**2位：前回高内容から7〜20日空いた台の再投入**
単なる長期放置ではなく、**前回高内容から少し空いて、なおかつ直近で凹んだ台**が強いです。「前日-1,500枚以下＋前回高内容から7〜20営業日」は、RB**1/299**、合算**1/142**、平均差枚**+281枚**でした。

**3位：本物履歴がある台の返済未完了**
直近21日合算が良い、直近14日RBが良い、しかし直近で連敗・凹みが残っている台は強いです。自由探索では「21日合算1/140以下＋14日RB1/300以下＋連敗2以上」が、21台ながらRB**1/269**、合算**1/132**、平均差枚**+644枚**でした。

**4位：1位一本釣りより、上位2〜3台を見る方が良い**
毎日1位はRB**1/322**ですが、上位2台に広げるとRB**1/310**、平均設定5・6推定率**33.0%**。この店は、ロジック1位だけに寄せるより、**上位2台の中で強化条件が重なる台を選ぶ**方が実戦向きです。

**5位：特定日は強く見えるが、専用ロジック化は見送り**

## 12. 実戦での使い方

**毎日の順位付け**
まず全日共通100点ロジックで全台を並べ、上位2〜3台を候補にします。1位だけに絞るより、上位2台の方がRB・p56が良いです。

**条件が出た日だけ打つ本命ルール**
自由Aまたは自由Bが出たら、100点ロジックより優先。特に「7日沈み＋21日合算良好＋前回高内容7〜20日前」は最上位です。

**Webアプリ条件列の補助ルール**
条件列には、85点以上、前日凹み＋再投入間隔、本命290、強280、最本命270を段階表示します。ただし強280/最本命270は件数が少ないため、小件数注意を併記します。

**見送り**
1位でも次点差8点以上、前日+2,000枚以上、直近7日+2,500枚以上、危険条件が複数、履歴不足は見送り寄りです。

## 13. 最終結論

この機種では、**100点満点ロジックを毎日の土台**にしつつ、実戦の本命は**自由度MAX条件**を優先するのが最も現実的です。

確認順は以下です。

1. 自由A/Bが出ていないか
2. 100点ロジックで上位2〜3台に入っているか
3. 前日-1,500枚以下、前回高内容7〜20日前、本物履歴が重なっているか
4. 前日大幅プラス、7日大幅プラス、次点差8点以上など危険条件がないか
5. 最後にWebアプリの段階条件で「広め」「本命」「強」「最本命」を確認

通常日専用・イベント日専用ロジックは作らず、**全日共通ロジックのみ**を実装する結論です。特定日は成績が良く見えますが、件数が13日と少なく、日付そのものの加点は禁止のため、専用化は過剰最適化と判断しました。
