# 3. 設定師のクセの仮説

強そうな順にまとめると、次の傾向です。

| 強さ | 仮説                    | 結論                                     |
| -: | --------------------- | -------------------------------------- |
|  1 | 21日累計で返済未完の台を返す       | 最重要。21日で大きく沈み、まだ返し切っていない台が強い           |
|  2 | 14日で適度に沈んだ台を使う        | 深すぎる沈みより、-1,500〜-6,000枚程度の「見えている凹み」が良い |

|  4 | 前回高内容から10〜14日程度空けて戻す  | 前日据え置きより、少し間を空けた再投入の方が良い               |
|  5 | 過去14日の合算が弱すぎない台を使う    | 合算150〜175、RB300〜450の「悪すぎない履歴」が良い       |

# 12. 実戦での使い方

毎日の順位付けには、**100点満点ロジック**を使います。ただし、点数だけで座るなら80点以上、できれば85点以上が目安です。75点前後は広く拾うには悪くありませんが、ネオアイムの56級狙いとしては弱めです。

条件が出た日だけ打つ本命ルールは、次の順番です。

| 優先 | 見る条件        | 実戦判断                       |
| -: | ----------- | -------------------------- |
|  1 | 自由C、RB270参考 | 件数少だが出現時は最優先。競合が強ければここから選ぶ |
|  2 | 自由A / RB290 | 最もバランスが良い本命条件              |
|  3 | 自由B / RB300 | 打てる日数と期待値のバランスが良い          |
|  4 | RB310広め     | 広く拾う条件。単独なら次点差や危険条件も確認     |
|  5 | 1位＋次点差8以上   | 段階条件が出ない日の代替本命             |
|  6 | 85点以上       | 点数閾値だけで見るなら最低このあたり         |
|  7 | 80点以上       | 代替候補。危険条件0〜1個が前提           |

見送りは、前日56級、前日+1500枚以上、14日RB450超、14日合算175超、危険条件2個以上、履歴14日未満です。

# 13. 最終結論

この店舗のネオアイムジャグラーEXは、**単純な据え置き狙い・長期放置ローテ狙いではなく、21日返済未完＋適度な沈み＋過去14日のボーナス内容が悪すぎない台** が狙い目です。

最終的な主軸は次の通りです。

| 用途         | 主軸                   |
| ---------- | -------------------- |
| 毎日の全台順位付け  | 100点満点ロジック           |
| Webアプリの条件列 | RB310〜RB270の段階的採用条件  |
| 実戦で最も優先    | 自由度MAX条件、特に自由A/B     |
| 見送り判断      | 危険条件、前日56級、処遇完了、履歴不足 |
| 通常日/特定日    | 分けずに全日共通のみ           |

結論として、**100点満点ロジックはランキング用、実戦の主軸は自由度MAX条件＋段階的採用条件** にするのが最も現実的です。

## 12. 実戦での使い方

### 毎日の順位付けに使うもの

まずは **全日共通100点ロジック**で全台に点数を付けます。
毎日見るなら、1位だけでなく `60点以上`、`1位＋次点差10以上`、危険条件の有無を確認します。

### 条件が出た日だけ打つ本命ルール

優先順位は次の順です。

1. **自由D：深い長期沈み＋3日大沈み**
2. **自由C：急落強＋未回収＋本物2回**
3. **自由E：5日沈み＋高稼働＋5連敗＋近隣高内容なし**
4. **1位＋次点差10以上**
5. **60点以上＋危険条件なし**

### Webアプリの条件列で見る補助ルール

Webアプリの条件列には、次の順で表示するのが良いです。

| 優先 | 表示条件                  |
| -: | --------------------- |
|  1 | 本命290                 |
|  2 | 弱本命300                |
|  3 | 広め310                 |
|  4 | 強280                  |
|  5 | 最本命270は現時点では非表示または未採用 |

`強280` はRBだけなら良いですが、差枚とRB1/400超率に不安があるため、`本命290` より上には置かない方がよいです。

## 13. 最終結論

この機種では、**100点満点ロジックを毎日の土台**にしつつ、実戦で最も優先すべきなのは **自由度MAX条件と次点差フィルタ**です。

| 判断                  | 結論                                   |
| ------------------- | ------------------------------------ |
| 100点満点ロジックを主軸にするべきか | 毎日の順位付けには主軸                          |
| 段階的採用条件を主軸にするべきか    | Web表示・座る価値の強弱表示に使う                   |
| 自由度MAX条件を主軸にするべきか   | 条件が出た日は最優先                           |
| 通常日/特定日専用ロジック       | 作らない                                 |
| 実戦確認順               | 自由D/C/E → 1位次点差10以上 → 60点以上 → 危険条件確認 |

最終的には、
**「自由条件が出た日は自由条件優先、出ない日は100点ロジックの1位＋次点差10以上、危険条件があれば見送り」**
が最も現実的です。

## 12. 実戦での使い方

毎日の順位付けには **100点満点ロジック**を使います。まず全台に点数を付け、1位・2位・3位を確認します。

条件が出た日だけ打つ本命ルールは、**87点以上＋強化3個以上＋危険0** です。これはRB1/306.6、合算1/134.2、平均差枚+505.9枚、機械割105.44%で、今回の実戦主軸に最も向いています。

Webアプリの条件列では、以下の順で表示するのが良いです。

```text
87点以上 = 広めRB310
90点以上 = 弱本命RB300
92点以上 = 本命RB290
92点以上＋強化5 = 強RB280、ただし件数不足注意
95点以上 = 参考RB270、常用非推奨
```

見送りは、**前日高内容、冷遇放置、処遇完了、危険条件2個以上**を優先してください。

## 13. 最終結論

この店舗・この機種では、**自由度MAX条件を主軸、100点満点ロジックを順位付け補助、段階的採用条件をWeb表示用**にするのが最も現実的です。

実戦確認順は次です。

```text
1. 危険条件を見る
2. 87点以上か確認
3. 強化条件が3個以上あるか確認
4. 90点以上なら本命寄り
5. 92点以上は強いが件数不足に注意
6. 前日高内容・冷遇放置なら見送り優先
```

一番おすすめは、**「87点以上＋強化3個以上＋危険0」**です。
毎日必ず座るなら1位でも改善しますが、ネオアイムで設定5・6級だけを狙う目的なら、毎日1位よりも87点以上条件に絞る方が実戦向きです。

ネオアイム設定推定率：
各台日のG数、BB、RBから、以下の設定別BIG/REG確率で設定1〜6の推定率を計算する。

設定1：BIG 1/273.1、REG 1/439.8
設定2：BIG 1/269.7、REG 1/399.6
設定3：BIG 1/269.7、REG 1/331.0
設定4：BIG 1/259.0、REG 1/315.1
設定5：BIG 1/259.0、REG 1/255.0
設定6：BIG 1/255.0、REG 1/255.0

設定ごとの重みは、G数をG、BB回数をB、RB回数をRとして、BIGとREGを別々の二項分布として対数尤度で計算する。
最大対数尤度を引いて指数化し、設定1〜6で正規化する。
設定5・6推定率 = 設定5推定率 + 設定6推定率。
設定4以下推定率 = 設定1〜4推定率の合計。
ネオアイムでは設定5・6級だけを成功、設定4以下は失敗寄りとして扱う。

高内容日の定義：
- 高内容：G数1500以上、かつ設定5・6推定率50%以上
- 強高内容：G数1500以上、かつ設定5・6推定率70%以上
この高内容ラベルは過去履歴の特徴量作成とバックテスト評価に使う。
当日の高内容ラベルを当日スコア計算に使ってはいけない。
