13. 最終結論

この機種では、100点満点ロジックを日々の順位付けの主軸 にしつつ、実戦の最優先は 自由度MAX条件 に寄せるのが最も現実的です。

結論は以下です。

判断	結論
100点満点ロジックを主軸にするべきか	毎日のランキング表示では主軸にするべき
段階的採用条件を主軸にするべきか	Webアプリの条件列では主軸にするべき
自由度MAX条件を主軸にするべきか	実戦の着席判断では最優先にするべき
通常日・特定日専用ロジック	今回は作らない。特定日件数が少なく、クセ差が明確ではない
最優先条件	上位3 + 70点以上 + 次点差12以上 + 返済未完 + 危険0
最重要回避条件	処遇完了、長期放置、上向きすぎ

実装すべき機種別ロジック名：

通常日専用ロジックとイベント日専用ロジック：
今回は作らない。
理由：
CSVには特定日列があり、特定日=はいをイベント日、いいえを通常日として比較したが、主対象期間では特定日が21日しかなく、通常日と明確に別ロジック化できるほどの再現性はない。
同じ「沈み・急角度・返済未完・処遇完了回避」のロジックが通常日/特定日ともに有効であり、特定日専用ロジックは過剰最適化になる可能性が高い。
したがって、全日共通ロジックのみを実装する。

Webアプリ上の表示：
- 全日共通ロジックを `機種別` 列に表示する。
- `通常日` 列、`特定日` 列には今回の専用ロジックは追加しない。
- 特定日だから加点する処理は絶対に入れない。

評価方針：
ネオアイムジャグラーEXでは、設定5・6級だけを成功扱いにする。
設定4以下は失敗扱いにする。
成功指標は、G数・BB・RBから計算する設定5・6推定率。
設定5・6推定率 = 設定5推定率 + 設定6推定率。
設定4以下推定率 = 設定1〜4推定率。
設定推定率の計算には、ネオアイムジャグラーEXの設定別BIG確率・REG確率を使い、二項分布尤度を対数で計算して正規化する。
