梅田さん、CSVを実データとして読み、指示書どおり「分析レポート」ではなく、最後にCodexが実装へ使える正本へ寄せて整理しました。今回の指示は、最終的に実装用正本へ集約する前提で、途中条件と最終採用条件を混ぜないことが明記されています。
また、CSV内の最新日は未完成の可能性があるため除外するルールに従い、2026-06-27を完全除外しました。

## 結論

やすだひばりヶ丘店のネオアイムジャグラーEXは、単純な「直近凹み」よりも、**中期では高内容を使われている台が、直近3〜7日で合算・推定内容を落とした後に戻される**パターンが最も使いやすいです。

特に通常採用の主軸はこれです。

```text
historyDays >= 21
&& p56Avg21 >= 0.30
&& combinedRate7 >= 160
&& combinedRate3 >= 155
```

実績は **105台、RB 1/285.4、合算 1/137.6、平均差枚 +367枚、機械割 102.38%、平均設定5・6推定率 40.1%** でした。

自由度MAXでは、次の条件が最も強いです。

```text
historyDays >= 21
&& diff21 <= -4000
&& semiHighCount7 == 0
&& semiHighCount21 <= 2
```

実績は **20台、RB 1/264.9、合算 1/128.6、平均差枚 +683枚、機械割 105.08%、平均設定5・6推定率 46.4%** でした。件数は少ないため過信は禁物ですが、出た日は点数ロジックより優先してよい条件です。

ネオアイムの評価は、指示どおり設定5・6級だけを成功扱いし、設定4以下は失敗寄りに見ました。
設定5・6推定率は、BIG・REG確率の設定別尤度を正規化して算出する方式に従いました。

# 3. 見えたクセ

# 11. 実戦での使い方
