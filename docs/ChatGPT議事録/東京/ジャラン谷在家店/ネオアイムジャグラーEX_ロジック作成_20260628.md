## 2. 高内容日の定義

ネオアイムは、平均機械割よりも **設定5・6級に座れたか** を重視しました。プロンプト上も、ネオアイムでは設定5・6級を成功、設定4以下を失敗寄りとして扱う前提です。

各台日の `G数・BB・RB` から、設定1〜6の尤度を計算し、以下を算出しました。計算は指定どおり、BIG確率とREG確率の二項分布尤度を設定別に出し、正規化しています。

| 指標     | 定義                                            |
| ------ | --------------------------------------------- |
| p56    | 設定5推定率 + 設定6推定率                               |
| p4以下   | 1 - p56                                       |
| 高内容候補  | G数2,500以上、かつ p56 50%以上                        |
| 強高内容候補 | G数2,500以上、かつ p56 70%以上                        |
| 成否評価   | p56平均、p56中央値、p56 50%以上率、p56 30%未満率、RB/合算分布で評価 |

最終ロジックでは、当日のp56を点数計算には使いません。前日以前のBB/RB/G数から計算できる `前日p56` や `直近14日内の高内容回数` だけを履歴特徴として使います。

## 12. 実戦での使い方

毎日の順位付けには、100点満点ロジックを使います。ただし、**1位でも次点差10点未満なら過信しない**でください。

条件が出た日だけ打つ本命ルールは、以下の順です。

1. **自由MAX最優先 / 最本命270**
2. **強条件280**
3. **本命290**
4. **弱め本命300**
5. **広め310**
6. それ以外は、1位＋次点差10以上を補助扱い

Webアプリの条件列では、`広め310 → 弱め本命300 → 本命290 → 強条件280 → 最本命270` の順に表示し、最上位に該当する条件名を出すのが分かりやすいです。

見送りは明確です。

* D14 > 0
* 前日p56 ≥ 50%
* 前日差枚 ≥ +1000枚 かつ 前日p56 ≥ 30%
* 危険条件2個以上
* 点数だけ高く、段階条件にも自由MAXにも該当しない台

## 13. 最終結論

この機種では、**100点満点ロジックを主軸にしすぎない方がよい**です。
100点ロジックは毎日の順位付けには使えますが、単体ではRB 1/350台までしか改善しません。

最も現実的なのは、以下の運用です。

| 優先順位 | 使うもの              | 理由                             |
| ---: | ----------------- | ------------------------------ |
|    1 | 自由MAX最優先 / 最本命270 | RB 1/256.2、p56平均51.6%。件数少ないが最強 |
|    2 | 強条件280            | RB 1/277.0、合算1/129.1で実戦本命      |
|    3 | 本命290             | RB 1/282.9でまだ狙える               |
|    4 | 広め310             | 打つ日を増やす妥協条件                    |
|    5 | 100点ロジック＋次点差10    | 本命条件がない日の補助                    |
|    6 | 点数だけ高い台           | 過信禁止                           |

**最終結論：実戦では「自由度MAX条件」を主軸、100点満点ロジックを補助、段階的採用条件をWeb表示用の価値ラベルとして使うのが最も現実的です。**
