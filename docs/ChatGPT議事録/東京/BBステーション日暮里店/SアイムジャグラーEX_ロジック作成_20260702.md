## 2. 高内容日の定義

今回の高内容は、CSVの「設定」列を説明変数に使わず、当日結果のG数・BB・RBからネオアイム仕様の設定1〜6推定率を計算しました。

```text
p56 = 設定5推定率 + 設定6推定率

highContent =
  (G >= 2500 && p56 >= 0.50)
  ||
  (G >= 3000 && rbRate <= 300 && combinedRate <= 140)

strongHighContent =
  (G >= 3000 && p56 >= 0.70)
  ||
  (G >= 3500 && rbRate <= 270 && combinedRate <= 135)

midHighContent =
  (G >= 2000 && p56 >= 0.30)
  ||
  (G >= 2500 && rbRate <= 330 && combinedRate <= 145)
```

## 3. 見えたクセ

この店のSアイムは、単純な「最近高内容がない台」よりも、**28日単位で深く沈んでいて、なおかつ直近3日以内に高内容の痕跡がある台**がかなり強く出ました。つまり、完全放置の凹み台ではなく、**一度使われた気配があるのに長期累計では返済未完了の台**が本命です。

逆に、直近7日で高内容がないだけ、RBが悪いだけ、前日高内容で大きく出た台の据え狙いは弱めでした。

## 10. 実戦での優先順位

実戦では、まず `E_最本命RB270自由MAX` を最優先にしてください。これは件数25台と少なめですが、RB 1/250.6、合算 1/124.2、平均差枚 +1190.6枚、p56>=50%が60.0%で、今回の中では一番「ネオアイム感覚の成功」に近い条件です。

次に `D_強RB280`、`C_本命RB290` を本命候補として見ます。`A` と `B` はすでにRBがかなり軽いので十分強いですが、打つ日を増やすための広め条件として扱い、同じ日に複数台出るなら score、rank、topGap で優先順位を付けます。
