# マルハン小岩店 / ネオアイムジャグラーEX Webアプリバックテスト照合ログ

## 記録の位置づけ

この記録は、ChatGPT回答に含まれるバックテスト結果と、Webアプリ画面で実際に表示されるバックテスト結果を照合するためのものです。

2026-06-28の再確認で実装差分を修正し、Webアプリ画面上の弱本命300がChatGPT回答のバックテスト結果と一致したため、照合状態は「照合済み」とします。

## 修正前のズレ

最初のWebアプリ実測では、採用条件名は `弱本命300_沈み前日凹み間隔` になっていたものの、実測値はChatGPT回答と一致していませんでした。

| 項目 | ChatGPT回答 | 修正前Web実測 |
|---|---:|---:|
| 台数 / 集計数 | 28 | 19 |
| 総G / 合計G数 | 152,228 | 110,727 |
| BB率 | 1/265.67 | 1/259.9 |
| RB率 | 1/291.07 | 1/281 |
| 合算 | 1/138.89 | 1/135 |
| 機械割 | 103.00% | 104.2% |
| 勝率 | 53.57% | 57.9% |

主な原因は次の2点です。

- `弱本命300` の採用条件に、ChatGPT回答の最終条件にはない `前日3000G以上` が混ざっていた。
- Webアプリの期間入力は予測日基準のため、終了日を `2026-06-16` にすると、除外すべき最新実績日 `2026-06-17` が集計に入っていた。

あわせて、ChatGPT回答で注意されていた131番台・132番台の履歴開始日も、店舗設定として明示しました。

## 実装修正

| 修正箇所 | 内容 |
|---|---|
| 採用条件 | `弱本命300` と、それを土台にする `本命290` は、回答どおり `angle14 <= -90`、`prevDiff <= -1000`、`daysSince56 8〜28営業日` で判定する |
| 点数計算 | 前日凹み加点の `prevG >= 3000` は点数用の根拠として残し、採用条件の必須条件からは外す |
| 履歴開始 | マルハン小岩店の131番台・132番台は、ネオアイムジャグラーEXについて `2026-04-06` から履歴開始として扱う |
| キャッシュ | 店舗ごとの履歴リセット設定をバックテストキャッシュ署名に含め、履歴開始条件を変えた後に古い候補行を再利用しない |
