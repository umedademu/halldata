## 現時点の判定

要修正。

機種別採用条件のラベルは `弱本命300_沈み前日凹み間隔` を指しており、ラベル上のバックテスト説明も `28台 / RB1/291.07 / 平均+489枚 / 平均56 39.78%` になっています。

しかし、Webアプリ画面で同条件を実測すると `19台 / RB1/281 / 合算1/135 / 機械割104.2%` となるため、ラベルに書かれているバックテスト結果とWebアプリ実測結果が一致していません。
