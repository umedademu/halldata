## 2. 高内容日の定義

ネオアイムジャグラーEXでは、設定5・6級に座ることを成功、設定4以下を失敗寄りとして扱う必要があります。
そのため、各台日のG数、BB、RBから、設定1〜6のBIG/REG二項尤度を対数で計算し、設定5・6推定率を出しました。計算方法は、G、BIG、REGから設定別重みを出して正規化する指定に従っています。

今回の分析では、以下を使い分けました。

| 種類       | 定義                                                          | 使い道          |
| -------- | ----------------------------------------------------------- | ------------ |
| 設定5・6推定率 | BB/RB/Gから計算した設定5+6の推定率                                      | 成功評価の最重要指標   |
| 高内容日     | G数3,000以上かつRB1/300以下かつ合算1/140以下、またはG数4,000以上かつ設定5・6推定率50%以上 | 履歴上の投入・処遇判定  |
| 強高内容日    | G数4,000以上かつ設定5・6推定率70%以上                                    | 強い見せ場・処遇完了判定 |
| 前日高内容不発  | 前日G数3,000以上、設定5・6推定率50%以上、差枚+1,000枚未満                       | 据え・再投入候補     |
| 前日内容未払い  | 前日G数3,000以上、RB1/300以下、合算1/145以下、差枚+1,000枚未満                 | 自由探索の強化条件    |

重要なのは、当日のBB/RB/G/差枚はスコア計算には使っていない点です。スコアは必ず前日以前の履歴だけで計算しました。未来情報は使わないという指定に従っています。

## 12. 実戦での使い方

毎日の順位付けには、**100点満点ロジック**を使うのが良いです。まず全台に点を付け、1位・2位・3位を見ます。

条件が出た日だけ打つ本命ルールは、次の順番です。

1. `1位+次点差10以上+前日高内容不発`
2. `1位+次点差8以上+14日高内容0回`
3. `1位+75点以上+次点差8点以上`
4. `75点以上+14日沈み`
5. `自由広め：14日返済未完`

Webアプリの条件列で見る補助ルールは、`75点以上`、`1位75+差8`、`差8+高内容14日0`、`差10+前日不発`、`差12+前日不発`の5段階が良いです。

見送りは明確です。前日近隣2台が高内容、14日高内容5回以上、履歴7日未満、危険条件2つ以上、1位でも次点差が小さい日は、無理に座らない方が良いです。

## 13. 最終結論

この機種では、**100点満点ロジック単体を主軸にするより、100点ロジックで順位を作り、段階的採用条件と自由度MAX条件で座る日を絞るのが最も現実的**です。

| 判断           | 結論                        |
| ------------ | ------------------------- |
| 100点満点ロジック   | 毎日の順位付けの主軸                |
| 段階的採用条件      | Webアプリ表示の主軸               |
| 自由度MAX条件     | 実戦で最優先すべき本命ルール            |
| 最も安定した実戦条件   | 自由広め：14日返済未完              |
| 最も強いが件数注意の条件 | 1位+次点差10以上+前日高内容不発        |
| 見送り最重要条件     | 前日近隣2台高内容、14日高内容5回以上、履歴不足 |

実戦の確認順は、**危険条件 → 自由度MAX条件 → 段階的採用条件 → 100点順位**が良いです。
スコアが高くても危険条件が強ければ見送り、逆にスコアがやや低くても14日返済未完・前日不発・次点差が揃えば狙い候補にできます。
