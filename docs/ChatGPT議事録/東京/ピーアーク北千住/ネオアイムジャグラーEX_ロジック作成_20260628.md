## 2. 高内容日の定義

ネオアイム特例として、成功は **設定5・6級に座れたか** で評価しました。
各台日について、G数・BB回数・RB回数から設定1〜6の尤度を出し、設定5推定率 + 設定6推定率を **設定5・6推定率** としました。計算は指定どおり、BIGとREGを別々の二項分布として扱い、対数尤度を正規化しています。

実戦用ロジックでは、当日結果である設定5・6推定率は **目的変数・検証指標** としてのみ使用し、当日前に分からない情報として点数計算には使っていません。

| ----- | ------------------------------------------ |
| 高内容50 | 当日G数3000G以上、かつ設定5・6推定率50%以上                |
| 高内容70 | 当日G数3000G以上、かつ設定5・6推定率70%以上                |
| 成功寄り  | 設定5・6推定率50%以上、RB 1/300以下、合成 1/140以下が多い条件   |
| 失敗寄り  | 設定5・6推定率30%未満、設定4以下推定率70%以上、RB 1/400超が多い条件 |

全体母集団はかなり弱めです。

## 3. 設定師のクセの仮説

強い順にまとめると、この機種は **「前日〜短期でしっかり沈んだ台を、直近56投入過多でなければ返す」** クセが最も強いです。

### クセ1：前日大凹みの上げ

前日差枚が **-1500枚以下** で、かつ直近21日内の高内容回数が多すぎない台が強いです。

| 条件                        | 台数 |      RB |      合算 |    平均差枚 |     機械割 | 平均56率 |
| ------------------------- | -: | ------: | ------: | ------: | ------: | ----: |
| 前日-1500枚以下 + 21日内56回数2回以下 | 22 | 1/288.0 | 1/137.4 | +463.5枚 | 102.92% | 40.0% |

### クセ2：前日ボーナス内容が弱い台を返す

特に、前日3000G以上回されていて **合算1/180より悪い** 台が、翌日強くなりやすいです。
ただし、これ単独ではなく、前日大凹み・直近56過多でないことと重なると本命化します。

| 条件                                     | 台数 |      RB |      合算 | 平均56率 | 56率50%以上 |
| -------------------------------------- | -: | ------: | ------: | ----: | -------: |
| 前日-1500枚以下 + 前日合算1/180超 + 21日内56回数2回以下 | 16 | 1/262.8 | 1/132.6 | 48.9% |    43.8% |

### クセ3：日内1位が大きく抜けた日だけ強い

毎日1位を打つだけでは足りません。
1位と2位の点差が **15点以上** になると、合算・差枚・設定5・6推定率が改善します。

| ------------ | --: | ------: | ------: | ------: | ------: | ----: |

| 1位 + 次点差15以上 |  37 | 1/327.7 | 1/143.0 | +362.4枚 | 102.32% | 30.4% |
| 1位 + 次点差20以上 |  21 | 1/313.6 | 1/140.2 | +487.3枚 | 102.92% | 33.0% |

### クセ4：出た台・前日強内容台の据え置きはかなり弱い

この店のネオアイムは、強く見えた翌日の据え狙いより、沈み返しの方が合っています。

## 12. 実戦での使い方

### 毎日の順位付けに使うもの

**100点満点ロジック** を使います。
ただし、毎日1位を無条件に打つのではなく、次点差・強化条件・危険条件を必ず見ます。

最低ラインは以下です。

```text
狙い度70点以上
かつ 危険条件0〜1個
かつ 強化条件2個以上
```

### 条件が出た日だけ打つ本命ルール

優先順位はこれです。

1. **最本命270**
   `1位 + 前日-1500枚以下 + 前日合算1/180超 + 21日内56回数2回以下`
2. **強280**
   `前日-1500枚以下 + 前日合算1/180超 + 21日内56回数2回以下`
3. **本命290**
   `前日-1500枚以下 + 21日内56回数2回以下`
4. **1位+次点差15以上**
   ただし、前日強内容・前日出玉処遇がある場合は下げる
5. **95点以上**
   広め条件。単独では過信しない

### Webアプリの条件列で確認する補助ルール

Webアプリでは、以下の順に表示価値を付けるのが良いです。

```text
最本命270 ＞ 強280 ＞ 本命290 ＞ 弱本命300 ＞ 広め310 ＞ 70点+危険0 ＞ 1位+差15
```

### 見送り

以下は高スコアでも見送り推奨です。

```text
前日+1500枚以上
前日3000G以上かつRB1/250以下
前日3000G以上かつ合算1/120以下
直近10日差枚+3000枚以上
危険条件2個以上
履歴21日未満
```

## 13. 最終結論

この店舗・この機種では、**100点満点ロジックを主軸にしすぎない方が良い** です。

最も現実的なのは、

```text
100点満点ロジックで毎日の順位を作る
↓
Webアプリ用の段階的条件で価値を確認する
↓
自由度MAXの「前日大凹み + 前日合算弱 + 直近56過多でない」条件を最優先する
```

という使い方です。

結論を分けると以下です。

| 判断                  | 結論                                          |
| ------------------- | ------------------------------------------- |
| 100点満点ロジックを主軸にするべきか | 毎日の順位付け用としては使う                              |
| 段階的採用条件を主軸にするべきか    | 実戦採用判断の主軸にする                                |
| 自由度MAX条件を主軸にするべきか   | 最本命270・強280は点数ロジックより優先                      |
| 通常日専用ロジック           | 作らない                                        |
| イベント日専用ロジック         | 作らない                                        |
| 最優先条件               | 1位 + 前日-1500枚以下 + 前日合算1/180超 + 21日内56回数2回以下 |
| 見送り最重要              | 前日強内容、前日+1500枚以上、危険条件2個以上                   |
