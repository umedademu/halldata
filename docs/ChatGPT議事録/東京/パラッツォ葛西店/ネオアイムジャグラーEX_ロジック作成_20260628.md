梅田さん、CSVをもとに **パラッツォ葛西店 × ネオアイムジャグラーEX** の狙い台ロジックを作りました。目的は、過去CSVから設定師のクセを分析し、翌日の高設定投入位置を予測する100点満点ロジックを作ることです。
最終ロジックでは、CSV内の既存 `狙度` / `次差` / `ブドウ` は使わず、最新日も除外しました。これはプロンプト上、最新日は営業途中の可能性があり、狙度・次差・ブドウ系列を説明変数に使わない指定があるためです。 また、判定対象日の当日結果は点数計算に使わず、各台の前日以前の履歴だけでスコア化しています。

## 2. 高内容日の定義

ネオアイムジャグラーEXはプロンプト指定どおり、**設定5・6級に座れたか**を最重要指標にしました。設定4以下は今回の狙い台ロジックでは成功扱いにしません。

各台日について、G数・BB回数・RB回数から設定1〜6の尤度を計算し、以下を評価指標にしました。

| 指標            | 使い方                   |
| ------------- | --------------------- |
| 設定5・6推定率      | 最重要。`設定5推定率 + 設定6推定率` |
| 設定5・6推定率50%以上 | 実戦上の成功寄り              |
| 設定5・6推定率70%以上 | 強い成功                  |
| 設定5・6推定率30%未満 | 低設定寄りの失敗候補            |
| 設定4以下推定率70%以上 | 失敗寄り                  |
| RB確率          | ネオアイムの主軸評価            |
| 合算確率          | RBの裏付け                |
| 機械割           | 最後に確認する補助指標           |

バックテスト母集団は以下です。

| 母集団 | 対象日数 |   台数 |     RB確率 |       合算 |     平均差枚 |     機械割 | 平均56推定率 | 56推定率50%以上 | 56推定率30%未満 |
| --- | ---: | ---: | -------: | -------: | -------: | ------: | ------: | ---------: | ---------: |
| 全体  |  123 | 2706 | 1/359.61 | 1/153.75 |  -21.44枚 |  99.88% |  21.34% |     11.35% |     74.46% |
| 通常日 |   99 | 2178 | 1/369.45 | 1/155.97 |  -82.17枚 |  99.48% |  20.09% |      9.50% |     76.95% |
| 特定日 |   24 |  528 | 1/334.23 | 1/147.75 | +229.05枚 | 101.00% |  26.51% |     18.94% |     64.20% |

この差が大きいため、**全日共通ロジックに加えて、通常日専用ロジックと特定日専用ロジックも作るべき**です。
ただし、点数項目に「特定日だから加点」は入れません。通常日母集団・特定日母集団を分け、その中で履歴差・沈み・近隣状況を見る形にします。

## 3. 設定師のクセの仮説、強そうな順

### 3-1. 特定日は明確にベースが上がるが、強い台は「沈み角度＋上位集中」で出る

特定日は全体でRB 1/334.23、平均56推定率26.51%まで上がります。
その中でも、特定日専用スコアで **1位・90点以上・7日沈み角度が強い台** は、RB 1/269.13、平均56推定率53.22%まで改善しました。

### 3-2. 通常日は「近隣高内容後の横展開」がかなり強い

通常日は全体では弱いですが、
**通常日専用スコア上位2台以内 ＋ 前日近隣が高内容寄り**
の条件は、RB 1/301.27、平均56推定率37.63%でした。

さらに前日凹みも重なると、RB 1/295.63、平均56推定率39.26%まで上がります。
通常日は単純な凹みより、**近隣で見せた後に横へ寄せるクセ**が重要です。

### 3-3. 単純な連敗より「7日差枚角度」と「5日・14日沈み」が効く

ただ負けているだけより、
`7日差枚 ÷ 7日G数` が急角度で沈んでいる台の方が使いやすいです。
特に特定日では、7日沈み角度が強い台を1位条件と組み合わせると別格でした。

### 3-4. 島内の端寄り・近端寄りは少し優遇傾向

固定台番加点はしません。
ただし、台番をブロックに分けたとき、ブロック端・端から2台以内は、全体よりRB・56推定率がやや良く、少額加点に値します。

| 条件      |   台数 |     RB確率 |       合算 | 平均56推定率 |
| ------- | ---: | -------: | -------: | ------: |
| 近端以外    | 1230 | 1/367.34 | 1/154.95 |  20.29% |
| 端から2台以内 | 1476 | 1/353.73 | 1/152.82 |  22.21% |

### 3-5. 出玉だけで出た台、前日高内容でしっかり出た台は危険

前日高内容で大きく出た台、BB寄りで出ただけの台は、翌日が弱くなりやすいです。
これは「処遇完了」扱いとして減点・危険条件に入れます。

## 13. 最終結論

この機種では、**100点満点ロジックだけを主軸にするより、自由度MAX条件を優先した方が実戦向き**です。

最終判断は以下です。

| 判断項目       | 結論                                |
| ---------- | --------------------------------- |
| 100点満点ロジック | 毎日の順位付け・Webアプリ表示の土台として使う          |
| 段階的採用条件    | Webアプリの条件列で、座る価値の強弱を見せる用途         |
| 自由度MAX条件   | 実戦の本命判断では最優先                      |
| 通常日        | `通常上位2＋近隣強`、できれば前日凹み重複を狙う         |
| 特定日        | `特定1位＋90点以上＋7日沈み角度≤-0.090` を最優先   |
| 全日共通       | `1位＋次点差10点以上` は汎用本命               |
| 見送り        | 危険条件2個以上、処遇完了、BB寄り出玉後、次点差なしの低スコア台 |

実戦の確認順は、
**自由度MAX条件 → 通常日/特定日専用条件 → 全日共通スコア → 危険条件 → 次点差**
が最も現実的です。

## 13. 実戦での使い方

### 毎日の順位付け

まず `機種別` の全日共通スコアを見る。
目安は、**90点以上で候補、95点以上で本命候補、1位＋次点差10点以上なら強化**です。

### 条件が出た日だけ打つ本命ルール

最優先は次の順です。

1. **特定日＋5日深沈み＋3日悪合成**
2. **特定日＋上位3＋5日深沈み＋5日悪合成**
3. **共通85点以上＋2日深沈み＋3日悪合成**
4. **通常日＋前回強高内容22〜28日＋5日角度沈み**
5. **共通90点以上＋危険0＋強化2個以上**

### Webアプリ条件列で見る補助ルール

`条件` 列には、RB段階のラベルを出すのがよいです。

| 表示       | 意味                  |
| -------- | ------------------- |
| RB310広め  | 座る候補に入れる            |
| RB300弱本命 | p56重視で候補            |
| RB290本命  | 特定日なら優先             |
| RB280強   | 特定日の強条件             |

| 見送り      | 前日高内容、出過ぎ、通常日長期連敗など |

## 14. 最終結論

この機種では、**100点満点ロジック単体を主軸にしすぎない方がよい**です。
全日共通100点ロジックは毎日の順位付けには有効ですが、RB 1/310以下を安定して狙うには、点数に加えて「深沈み」「悪合成」「特定日専用」「通常日ローテ間隔」を重ねる必要があります。

最も現実的な運用は次の順です。

1. **全日共通スコアで候補を絞る**
2. **危険条件を除外する**
3. **特定日なら深沈み悪合成を最優先**
4. **通常日なら前回強高内容22〜28日＋沈み角度を重視**
5. **最後に次点差10点以上を確認する**

主軸は、
**自由度MAX条件 ＞ 段階的採用条件 ＞ 100点満点ロジック単体**
の順で使うのが実戦向きです。

## 3. 設定師のクセの仮説

強かった順です。

| 強さ | クセ                            | 根拠                                            |
| -: | ----------------------------- | --------------------------------------------- |
|  1 | **直近5日で深く沈んだ台を返す**            | prev5差枚 -5,000枚以下が強条件の土台になった                  |
|  2 | **直近3日の合算が悪く見える台を返す**         | prev3合算1/180以上が重なるとRBが一気に改善                   |
|  3 | **高稼働で沈んだ台が特に強い**             | prev7G 35,000G以上が加わるとRB1/279.5、平均56 50.1%まで上昇 |
|  4 | **4連敗前後がピーク**                 | ただの連敗ではなく、深沈み＋合算弱と重なる4連敗が強い                   |
|  5 | **処遇完了台は弱い**                  | 前日高内容、直近で戻した台、直近で高内容が複数回ある台は弱化                |
|  6 | **特定日は全体ベースでは強いが、専用ロジック化は危険** | 特定日は良いが22日しかなく、台ごとのクセは共通ロジックの方が安定             |

特定日列がある場合は通常日・イベント日の差を検証する指定があるため比較しましたが、専用ロジックを作るほどの件数と再現性は不足していました。

## 12. 実戦での使い方

### 毎日の順位付けに使うもの

まず100点満点ロジックで全台に点数を付けます。ただし、**1位だから必ず打つ**は弱いです。最低でも80点以上、できれば強化条件3個以上が必要です。

### 条件が出た日だけ打つ本命ルール

優先順位は以下です。

1. **強280**：深5沈み＋高稼働＋3日合算弱＋1位
2. **本命290**：深5沈み＋3日合算弱＋4連敗＋1位
3. **弱本命300**：1位＋80点以上＋強化3以上＋危険0
4. **広め310**：1位＋80点以上
5. **最本命270参考**：出たら強いが件数不足なので、強280の上位版として扱う

### Webアプリの条件列で確認する補助ルール

Webアプリでは、条件列に「広め310」「弱本命300」「本命290」「強280」「最本命270参考」を表示し、RB段階で価値を見せるのがよいです。

| 見送り          | 理由        |
| ------------ | --------- |
| 1位でも80点未満    | 打つ価値が薄い   |
| 1位でも強化条件1個以下 | ほぼベース並み   |
| 前日高内容台       | 据え置き傾向が弱い |
| 直近で大きく戻した台   | 処遇完了の可能性  |
| 長期未高内容だけの台   | 放置台の可能性   |

## 13. 最終結論

この機種では、**100点満点ロジック単体を主軸にしすぎない方がよい**です。

| 使い方           | 主軸にするべきか  | 理由                                        |
| ------------- | --------- | ----------------------------------------- |
| 100点満点ロジック    | 補助主軸      | 全台順位付けには有効。ただし毎日1位だけではRB1/329.2で弱い        |
| 段階的採用条件       | 実戦主軸      | 条件の強弱をWebアプリ上で見せやすい                       |
| 自由度MAX条件      | **最優先主軸** | 強280がRB1/279.5、合算1/133.7、平均56 50.1%で最も現実的 |
| 通常日専用・イベント日専用 | 作らない      | 特定日は強いが22日しかなく、専用ロジックは過剰最適化になりやすい         |

実戦では、**自由B/強280 → 本命290 → 弱本命300 → 広め310 → 危険条件チェック → 見送り判断**の順で確認するのが最も現実的です。
