今回は、分析レポートよりも「Codexがそのまま実装・照合できる正本」に寄せてまとめます。元プロンプトでも最終目的は分析レポートではなく実装用正本であること、途中条件と最終採用条件を混ぜないことが指定されています。 また、CSV内の最新日は営業途中の未完成データの可能性があるため、2026-06-14は除外しました。

## 最終結論

ジャンボのネオアイムジャグラーEXは、**全台共通の100点ロジックで毎日1位を取る使い方が最も現実的**です。
特に強いのは、単純な凹み台ではなく、次の複合です。

**14日REG枯れ・21日合成悪化・14日沈み・前回5/6級から22〜35日空き・直近高内容なし・一定以上のG数信頼度**。

一方で、特定日だけを別ロジックにするほどの再現性はありませんでした。むしろ今回データでは、通常日のほうが安定しており、特定日専用ロジックは過剰最適化になりやすいです。Webアプリ上は、**全日共通ロジックのみを機種別列へ実装**し、通常日列・特定日列の専用ロジックは作らないのが安全です。

設定推定：
各台の実績G数を G、BIG回数を B、REG回数を R とする。
設定sの BIG確率を pB_s、REG確率を pR_s とする。

対数尤度：
logLike_s =
B * log(pB_s) + (G - B) * log(1 - pB_s)
+ R * log(pR_s) + (G - R) * log(1 - pR_s)

設定間の比較では組み合わせ項は設定間で同一のため省略してよい。
最大logLikeを引いてexpに戻し、合計1になるよう正規化する。

p56 = 設定5推定率 + 設定6推定率
p4lower = 設定1〜4推定率合計

高内容判定：
high50 = G >= 3000 && p56 >= 0.50
high70 = G >= 3000 && p56 >= 0.70
contentStrong = G >= 3000 && (p56 >= 0.50 || (rbRate <= 300 && combinedRate <= 140))

合成列はCSVの文字列を信用せず、G / (BB + RB) で再計算する。
