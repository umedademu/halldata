# 2. 高内容日の定義

ネオアイムジャグラーEXは、設定5・6級に座れた割合を最重要指標にしました。指示上も、ネオアイムでは設定5・6級のみを成功、設定4以下を失敗扱いにする前提です。

設定推定は、当日の `G数・BB・RB` から設定1〜6のBIG確率・REG確率に対する尤度を計算し、正規化して `設定5・6推定率 = p5 + p6` を出しました。設定別ボーナス確率と推定率計算の考え方は、指示書のネオアイム特例に従っています。

今回の内部定義は以下です。

| 定義       | 条件                              | 用途         |
| -------- | ------------------------------- | ---------- |
| 設定5・6推定率 | p5 + p6                         | 最重要の成否指標   |
| 設定4以下推定率 | p1〜p4合計                         | 失敗寄り指標     |
| 高内容      | G数3,000以上 かつ 設定5・6推定率50%以上      | 過去履歴の高内容判定 |
| 強高内容     | G数4,000以上 かつ 設定5・6推定率70%以上      | 強い過去履歴判定   |
| 良ボーナス内容  | G数3,000以上、RB 1/300以下、合算 1/140以下 | 不発据え・本物感判定 |
| 出切り・処遇完了 | 前日差枚+1,000枚以上、または高内容で+1,000枚超   | 危険条件       |

`設定`列は存在しましたが、最終ロジックにも主検証にも使っていません。実戦前に使えるのは、前日以前の差枚・G数・BB・RB・そこから計算した過去のRB/合算/推定率だけです。

# 12. 実戦での使い方

毎日の順位付けには、**100点満点ロジックの順位**を使います。まず全台に点数を付け、1位、次点差、危険条件を確認してください。

本命ルールは、上から順に確認します。

1. **連敗4以上＋1位＋次点差5以上**
   最強だが27台と少なめ。空いていれば最優先。

2. **100点＋1位＋次点差3以上**
   RB 1/267.3。最本命扱い。ただし33台なので過信は禁物。

3. **狙い度1位**
   毎日使える主軸。RB 1/285.5。

4. **90点以上＋上位3**
   1位が取れない日の代替候補。RB 1/295.4。

5. **85点以上**
   広め条件。台数が多いので、強化条件が1つ以上ある台を優先。

見送りは明確です。前日+500枚以上、高内容で+1,000枚超、直近3日で出切り、履歴低信頼の台は、スコアが高くても優先度を下げます。

# 13. 最終結論

この機種では、**100点満点ロジックを毎日の土台にし、自由度MAX条件で本命だけ絞る**のが最も現実的です。

結論は以下です。

| 用途        | 主軸                           |
| --------- | ---------------------------- |
| 毎日の順位付け   | 100点満点ロジック                   |
| 座る価値の段階表示 | Webアプリ用の段階的採用条件              |
| 本命日だけ打つ   | 自由度MAX条件                     |
| 最優先確認     | 100点＋1位＋次点差、または連敗4以上＋1位＋次点差5 |
| 見送り判断     | 前日出切り、高内容出切り後、強化条件なし         |

通常日専用・イベント日専用ロジックは作らず、全日共通ロジックだけを実装するのがよいです。特定日は全体期待が上がって見えますが、点数項目に `特定日だから加点` は入れません。

## 12. 実戦での使い方

毎日の順位付けは、**100点満点ロジック**を使います。まず全台に点数を付け、日別1位、上位3台、次点差を確認します。

条件が出た日だけ打つ本命ルールは、次の順番です。

1. **90点以上**
2. **1位＋次点差8点以上**
3. **1位＋次点差6点以上**
4. **5日RB<=250＋強化2＋危険0**
5. **前日高内容不発**
6. **前日深凹み＋処遇未完**
7. **日別1位＋次点差4点以上**

Webアプリの条件列では、次のように見ればよいです。

| -------- | ------------------ |

| 強化0〜1    | 点数が高くても優先度を下げる     |

## 13. 最終結論

この機種では、**100点満点ロジックを毎日の順位付けの主軸にし、自由度MAX条件を本命フィルターとして上乗せする**のが最も現実的です。

通常日専用ロジックとイベント日専用ロジックは、今回は作らない方がよいです。理由は、特定日がバックテスト期間で15日しかなく、特定日専用にすると条件が極端にブレるためです。特定日全体のベースは強いものの、日付そのものを加点せず、全日共通の「沈み・不発・未処遇」ロジックで見るのが安全です。

最終優先順位はこうです。

| 優先  | 内容                             |
| --- | ------------------------------ |
| 1   | 自由度MAXの強条件、特に5日RB<=250＋強化2＋危険0 |
| 2   | 100点ロジックの日別1位＋次点差8点以上          |
| 3   | 100点ロジックの日別1位＋次点差6点以上          |
| 4   | 前日高内容不発                        |

| 見送り | 処遇完了、強化0〜1、低履歴、BB寄り出玉後         |

## 13. 最終結論

この機種では、**100点満点ロジックだけを主軸にするより、100点ロジックで順位を出し、自由度MAX条件で本命を確定する使い方が最も現実的**です。

結論は以下です。

| 判断         | 結論                                 |
| ---------- | ---------------------------------- |
| 100点満点ロジック | 毎日の順位付けに使う                         |
| 段階的採用条件    | Webアプリの条件列で価値の強弱を見せる               |
| 自由度MAX条件   | 実戦の最優先ルールにする                       |
| 通常日/特定日専用  | 作らない。全日共通のみ                        |
| 最優先条件      | 前日-1000以下 + 14日RB320以下 + 7日高内容2回以上 |
| 見送り最重要     | 前日+1000以上、前日合成130以下、7日高稼働+前日良合成    |

実戦確認順は、

**自由最本命条件 → 7日RB300+前日凹み → 返済未完+本物感 → 機種別1位/次点差4以上 → 80点以上 → 危険条件確認**

が良いです。
