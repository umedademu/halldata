# 2. 高内容日の定義

ネオアイムジャグラーEXなので、成功判定は **設定5・6級に座れたか** を主軸にしました。設定4以下は成功扱いにしていません。これはプロンプト上でも、ネオアイムは設定5・6級だけを成功、設定4以下を失敗として扱う指定があるためです。

各台日の設定5・6推定率は、G数・BB・RBから設定1〜6のBIG確率・REG確率を使って対数尤度で算出し、設定5推定率＋設定6推定率を `p56` としました。計算思想は、プロンプトで指定されたBIG/REGの二項尤度方式に従っています。

今回の履歴ラベルは次のように定義しました。

| ラベル   | 定義                                           | 用途           |
| ----- | -------------------------------------------- | ------------ |
| 高内容   | G数3,000以上、かつ設定5・6推定率50%以上                    | 履歴上の投入痕跡     |
| 強高内容  | G数3,000以上、かつ設定5・6推定率70%以上                    | 強い据え・連続投入候補  |

# 13. 最終結論

この機種では、**100点満点ロジックを単独主軸にするより、自由度MAX条件を最優先し、100点ロジックはランキング補助として使う** のが現実的です。

最終判断は次の順です。

```text
1. 自由A「直近7日高内容2回＋7日差枚角度+150以上」が出ているか
2. Web条件のRB280/RB290段階に該当するか
3. 90点以上＋7日合算1/140以下に該当するか
4. 90点以上＋危険0か
5. 見送り条件がないか
6. 最後に日別順位と次点差を見る
```

通常日専用・イベント日専用ロジックは今回は作らず、**全日共通ロジックのみ** でよいです。特定日は全体的に見栄えが良いものの、件数が少ない強条件を日付種別でさらに分けると過剰最適化になりやすいです。
