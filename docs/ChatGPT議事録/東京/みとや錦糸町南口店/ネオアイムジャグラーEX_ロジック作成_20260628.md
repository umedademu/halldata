CSVの最新日の行は営業途中データの可能性があるため除外し、狙い度・狙度・ブドウ・次差などの列は説明変数から外しました。
また、当日のG数・BB・RB・差枚・設定推定など、実戦時点で分からない未来情報は一切スコア計算に使っていません。

`特定日` は通常日／イベント日の比較検証には使いましたが、「特定日だから加点」は禁止ルールに従って入れていません。

## 2. 高内容日の定義

ネオアイムジャグラーEXなので、成功判定は **設定5・6級に座れたか** を主軸にしました。設定4以下は今回の目的では成功扱いにしていません。

各台の当日結果について、G数・BB回数・RB回数から、設定1〜6のBIG確率・REG確率を使った二項分布尤度を計算し、正規化して以下を出しました。

```text
設定5・6推定率 = 設定5推定率 + 設定6推定率
設定4以下推定率 = 設定1〜4推定率
```

履歴特徴量としては、以下を過去日のみから作成しました。

| ラベル | 定義                                                      | 用途                |
| --- | ------------------------------------------------------- | ----------------- |
| 強内容 | 設定5・6推定率50%以上、かつG数3,000G以上                              | 前回強内容からの日数、処遇完了判定 |
| 良内容 | 設定5・6推定率35%以上かつ2,500G以上、またはRB1/300以下・合成1/140以下・2,500G以上 | 直近の見せ場／未処遇判定      |
| 本物感 | RB1/300以下・合成1/145以下・2,500G以上、または設定5・6推定率50%以上・2,500G以上  | 据え置き・不発判定         |

`設定` 列は存在しましたが、最終ロジックにも検証ラベルにも使っていません。理由は、実戦で使うべき評価をG数・BB・RBから再計算した設定5・6推定率に統一したためです。

## 13. 最終結論

この機種では、**100点満点ロジックを毎日の順位付けの土台** にしつつ、実戦では **75点以上・70点以上・深沈み6連敗・次点差10点以上** を重視するのが最も現実的です。
