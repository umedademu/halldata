## 2. 高内容日の定義

ネオアイムジャグラーEXなので、成功判定は **設定5・6級に座れたか** を最重要にしました。依頼文でもネオアイムでは設定5・6級だけを成功、設定4以下を失敗寄りに扱う方針が指定されています。

各台日について、当日のG数、BB、RBから設定1〜6の尤度を計算し、以下を出しました。

* 設定5・6推定率 = 設定5推定率 + 設定6推定率
* 設定4以下推定率 = 設定1〜4推定率
* 高内容日 = G数3000以上、かつ設定5・6推定率50%以上
* 強高内容日 = G数3000以上、かつ設定5・6推定率70%以上
* 低内容寄り = 設定5・6推定率30%未満

設定推定率は、BIG確率とREG確率を別々に使った設定別尤度を正規化して計算しました。これは依頼文のネオアイム用の指定方法に沿っています。

全台ベースでは、履歴14日以上の1408台日で、RB 1/348、合算 1/153、平均差枚 -39.9枚、機械割99.63%、平均設定5・6推定率25.9%でした。ここからどれだけ **RB、合算、設定5・6推定率を引き上げられるか** を基準にロジックを作っています。

CSV内には「設定」列もありましたが、これは確定設定ではなく推定値系の列と判断し、最終ロジックの説明変数には使っていません。参考検証では、履歴14日以上全台の設定列平均3.21に対し、毎日1位は3.55、80点以上は3.79、最本命条件は4.35、見送り条件は2.97でした。方向性は今回の独自設定5・6推定率と概ね一致しています。

## 3. 見えた設定師のクセ

強い順にまとめると、以下です。

**1. 前日高内容の不発据えが強い。**
前日G数3000以上、設定5・6推定率50%以上、差枚+500枚未満の台は、翌日55件でRB 1/295、平均設定5・6推定率37.1%。特に前日G数3500以上、設定5・6推定率70%以上、差枚+500枚未満の「真不発」は18件でRB 1/276、合算1/134、平均差枚+470枚でした。

**2. 直近5〜7日の沈み返しが強い。**
5日差枚-2500枚以下かつ危険条件なしは178件でRB 1/305。さらに5日-2500枚以下かつ7日-3000枚以下の二重沈みは114件でRB 1/300、合算1/141、平均差枚+306枚まで上がりました。

**3. 直近で高内容を複数回見せた台の再投入がある。**
直近3日内に高内容が2回以上あり、スコア75点以上、直近3日の平均設定5・6推定率50%以上の条件は13件だけですが、RB 1/259、合算1/135、設定5・6推定率50%以上の割合61.5%。最も強いが件数は少ないです。

**4. 「出た台の追いかけ」は危険。**
5日差枚+2000枚以上はRB 1/393、7日差枚+2000枚以上はRB 1/395、30日差枚+5000枚以上はRB 1/398。かなり明確に弱いです。

**5. 通常日と特定日のクセは分けない方がよい。**
特定日は履歴14日以上で13日しかなく、件数不足です。60点以上は特定日でRB 1/276と強く見えますが、30台日しかなく、通常日と別ロジックにすると過剰最適化になりやすいです。したがって今回は **通常日専用・イベント日専用ロジックは作らず、全日共通ロジックのみ** にします。特定日だから加点もしません。

## 12. 実戦での使い方

毎日の順位付けは、**100点満点ロジックの1位** をまず見ます。1位の成績はRB 1/307、合算1/143、平均差枚+201枚なので、全台ベースからは明確に改善しています。

実際に座る本命ルールは、次の順番です。

1. **80点＋真不発**
   最強。RB 1/261、合算1/131、平均56推定率52.0%。件数14件なので出現時だけ最優先。

2. **3日内2高内容＋75点＋平均56強**
   RB 1/259、中央値56推定率60.2%。件数13件だが、出た日は最本命。

3. **直前真不発据え**
   点数が80点未満でも確認価値あり。RB 1/276。

4. **二重沈み＋危険0**
   件数114件あり、RB 1/300、平均差枚+306枚。実戦で一番使いやすい本命寄り条件。

5. **1位＋次点差10以上**
   ランキングで単独感がある日だけ打つ条件。RB 1/293。

6. **60点以上または上位2＋65点＋危険1以下**
   広めに拾うならここまで。複数台候補がある日は危険条件の少ない方を優先。

見送りは、**危険条件2個以上** を最優先で避けます。特に直近5日・7日・14日で出過ぎている台は、たとえ台番の印象が良くても外すべきです。

## 13. 最終結論

この機種では、**100点満点ロジックを毎日の順位付けの主軸** にし、実際の着席判断では **自由度MAX条件を上位フィルタとして優先** するのが最も現実的です。

* 100点満点ロジック：毎日全台に点を付ける土台として使う
* 段階的採用条件：Webアプリの条件列で、座る価値の強弱を見せる
* 自由度MAX条件：真不発、二重沈み、3日内2高内容が出た日の本命判断に使う

通常日専用・イベント日専用は作らない方がよいです。特定日の件数が少なく、専用ロジックにすると過剰最適化になります。Webアプリでは、全日共通ロジックだけを「機種別」列に表示する想定が最も安全です。

## 13. 最終結論

この機種では、**100点満点ロジックを毎日の順位付けに使い、実戦の主軸は自由MAX条件にする**のが最も現実的です。

| 判断項目                | 結論                                    |
| ------------------- | ------------------------------------- |
| 100点満点ロジックを主軸にするべきか | ランキング表示の主軸にするべき                       |
| 段階的採用条件を主軸にするべきか    | Webアプリの条件列では主軸にするべき                   |
| 自由度MAX条件を主軸にするべきか   | 実戦の座る/見送る判断では最優先                      |
| 通常日・イベント日で分けるべきか    | 分けない。特定日サンプルが少なく、クセ差も専用化するほどではない      |
| 実戦確認順               | 自由MAX条件 → 70点以上 → 危険条件なし → 順位 → 次点差参考 |

最も強い実戦ルールは、以下です。

```text
7日差枚≤-2500枚
かつ 7日差枚角度≤-120枚/1000G
かつ 7日G数18000以上26000未満

これを本命条件とし、
5〜8連敗が重なれば強条件、
さらに7日G数24000未満なら最本命。
```

## 13. 最終結論

この機種では、**100点満点ロジック単体を主軸にしすぎない方が良い** です。

最も現実的な使い方は以下です。

1. **全日共通100点ロジックで毎日の順位を作る**
2. **1位と2位の次点差を見る**
3. **前日高内容不発＋5日沈み＋未処遇があるかを見る**
4. **1位＋次点差8以上なら本命**
5. **1位＋前日不発据え、または自由本命条件なら点数より優先**
6. **通常日専用・イベント日専用ロジックは作らない**

主軸の優先順位は、

**自由度MAX条件 ＞ 段階的採用条件 ＞ 100点満点ロジック単体**

です。

100点満点ロジックはランキングの土台として必要ですが、実戦で最も期待値が高いのは **前日高内容不発の未処遇台** を拾うルールです。
