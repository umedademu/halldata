## 2. 高内容日の定義

ネオアイムジャグラーEXなので、成功判定は**設定5・6級に座れたか**を主軸にしました。設定4以下は今回の狙い台ロジックでは失敗寄りに扱います。これは、ネオアイムでは設定5・6級を成功、設定4以下を失敗として扱う指定に合わせています。

設定5・6推定率は、各台日のG数・BB・RBから、設定1〜6のBIG確率とREG確率を使って対数尤度で再計算しました。設定5・6推定率は設定5推定率＋設定6推定率です。

今回の高内容定義は以下です。

| 区分   | 定義                        | 用途              |
| ---- | ------------------------- | --------------- |
| 56級  | G数3,000以上、かつ設定5・6推定率50%以上 | 前日以前の高内容履歴、成功判定 |
| 強56級 | G数3,000以上、かつ設定5・6推定率70%以上 | 強い据え・連続投入の確認    |
| 低内容  | G数3,000以上、かつ設定5・6推定率30%未満 | 危険判定、放置判定       |
| RB補助 | RB 1/300以下                | ネオアイム段階条件の補助    |

## 3. 設定師のクセの仮説

強そうな順に並べると、今回の店・機種は次の傾向です。

**1位：直近で高内容を見せた台の短期再投入が強い。**
前日56級、直近5日内に56級が複数回、直近5日合成が良い台が強く、自由探索でも最上位条件はこの系統でした。単なる凹みよりも、「見えている高内容をもう一度使う」寄りです。

**2位：直近5日G数が多い、客に見られている台が優遇されやすい。**
5日累計G数25,000以上は単独でもRB **1/337.9**、平均設定5・6推定率 **26.4%**まで上がりました。ただし前半では弱く、単独ではなく高内容履歴や合成の本物感と組み合わせる方が安全です。

**3位：短期の深い沈みは返済候補になるが、長期沈みは弱い。**
5日差枚-4,000枚以下はRB **1/358.0**、7日差枚-5,000枚以下はRB **1/360.4**で改善しました。一方、沈み滞在が長すぎる台や30日間56級ゼロの台は弱く、放置台として扱うべきです。

**4位：前回56級からかなり空いた台は、過去に56級履歴がある場合だけ使える。**
「過去に56級があり、そこから28日以上空き」はRB **1/353.1**で改善しました。しかし「30日間56級ゼロ」はRB **1/412.6**と明確に弱いです。長期空き＝チャンスではなく、過去に使われた実績がある台だけ評価します。

**5位：イベント日は全体成績が少し良いが、専用ロジック化するほどの別クセは弱い。**
通常日85点以上はRB **1/304.6**、特定日85点以上はRB **1/302.6**で、方向性はほぼ同じでした。特定日の強条件は件数が少なすぎるため、通常日専用・イベント日専用ロジックは作らず、**全日共通ロジックのみ**を採用します。

## 5. 完成した100点満点の狙い度ロジック

ロジック名は、**ピーアーク竹ノ塚スタジオ_ネオアイムジャグラーEX_56再投入返済ロジック**です。

計算式は以下です。

```text
狙い度 = 35点
       + 稼働信頼度
       + 直近高内容・再投入要素
       + 返済未完了・短期沈み要素
       + 直近ボーナス本物感
       - 危険要素

最終点 = 0〜100点に丸める
```

## 12. 実戦での使い方

毎日の順位付けには、**100点満点ロジック**を使います。ただし、毎日1位に座るだけではRB1/368.0止まりなので、1位という理由だけでは弱いです。

1. **最優先**：88点以上＋直近5日合成1/150以下
2. **次点**：88点以上＋上位2台＋直近5日56級2回以上

4. **広めに拾う**：82点以上
