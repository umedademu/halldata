# 2. 高内容日の定義

ネオアイムは **設定5・6級に座れたか** を成功指標にしました。設定4以下は失敗扱いです。これは、提示プロンプトでネオアイムは設定5・6級を最重要指標とし、設定5・6推定率を「56に座るヒット率」の代理指標にする指定があるためです。

各台日について、G数・BB・RBから設定1〜6の尤度を出し、正規化して **設定5・6推定率 = 設定5推定率 + 設定6推定率** を計算しました。BIG/REG確率は提示表を使用し、設定推定率の計算方法も提示式に沿っています。

今回の高内容ラベルは次の通りです。

| ラベル    | 定義                               | 使い方               |
| ------ | -------------------------------- | ----------------- |
| 高内容    | 有効データかつG数2,500G以上かつ設定5・6推定率50%以上 | クセ検証の主ラベル         |
| 強高内容   | 有効データかつG数2,500G以上かつ設定5・6推定率70%以上 | 強い投入・本物感の確認       |
| 実戦ロジック | 当日前に分かる過去履歴だけで点数化                | 今日のG/BB/RB/差枚は不使用 |

2. **3〜6連敗はプラス、6連敗超はマイナス**。沈みが長すぎると放置台化します。
3. **前日高内容据えは弱い**。高内容だった翌日はRBも56推定率も落ちます。
4. **回されすぎ台は弱い**。直近7日22,000G以上は見えすぎ・処遇完了寄りです。
5. **特定日は順位だけで追うと弱い**。ただし80点以上など絶対スコアが高い台は通常日・特定日どちらでも有効です。

実戦では、次の順に確認するのが最も現実的です。

1. **自由度MAX本命条件** が出ているか
2. **90点＋危険0** または **85点＋危険0** があるか
3. なければ **80点以上** を広め候補として確認
4. 危険条件が1つでも強ければ見送り寄り
5. 80点未満は、基本的に座る理由が薄い

# 13. 最終結論

この機種では、**100点満点ロジックを順位付けの土台にしつつ、実戦主軸は段階的採用条件と自由度MAX条件に置く** のが最も現実的です。

* 100点満点ロジック：毎日の比較・Webアプリの `機種別` 列に使う
* 段階的採用条件：座る価値の強弱を表示する主軸
* 自由度MAX条件：条件が出た日だけ打つ本命ルール。特に「短期沈み3-6連敗」「強コンボA＋80点」は点数ロジックより優先してよい
* 通常日/特定日専用ロジック：作らない。特定日加点はしない
* 最低ライン：80点以上
* 本命ライン：85点＋危険0
* 強ライン：90点＋危険0
* 最本命：強コンボA＋80点
