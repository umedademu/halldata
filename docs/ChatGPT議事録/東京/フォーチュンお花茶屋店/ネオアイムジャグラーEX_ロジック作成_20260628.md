## 2. 高内容日の定義

ネオアイム用に、各台日の `G数 / BB / RB` から設定1〜6の尤度を計算し、以下を目的変数にしました。指示書の指定通り、設定5と6は分けず、`設定5・6推定率 = 設定5推定率 + 設定6推定率` として扱っています。

| 指標        | 定義                                |
| --------- | --------------------------------- |
| 設定5・6推定率  | BB/RBの二項分布尤度から算出した `p5 + p6`      |
| 設定4以下推定率  | `1 - 設定5・6推定率`                    |
| 高内容日      | `G数 >= 2000` かつ `設定5・6推定率 >= 50%` |
| 履歴上の高内容間隔 | 上記の高内容日を過去履歴として使う                 |
| 成績評価の優先順位 | RB確率 ＞ 合算確率 ＞ 機械割                 |

機械割は、指示書の式どおり `100 + 総差枚 ÷ 総G数 ÷ 3 × 100` で計算しました。

## 2. 高内容日の定義

ネオアイムジャグラーEXなので、成功判定は**設定5・6級に座れたか**を最重要にしました。指示上も、ネオアイムでは設定5・6級を成功、設定4以下を失敗として扱う必要があります。

### 設定推定の扱い

CSVの`設定`列は参考確認のみ。
最終ロジックには使っていません。

各台日のG数・BB・RBから、指定のネオアイム設定別ボーナス確率を使い、設定1〜6の尤度を計算しました。設定5・6推定率は、設定5推定率＋設定6推定率です。これは指示された計算方法に沿っています。

### 高内容日の定義

実戦用の履歴ラベルとして、以下を高内容扱いにしました。

| ラベル     | 定義                                                                    |
| ------- | --------------------------------------------------------------------- |
| 高内容日    | G数1500以上かつ設定5・6推定率50%以上、またはG数3000以上・設定5・6推定率40%以上・RB1/310以下・合算1/145以下 |
| 良内容日    | G数1500以上・RB1/310以下・合算1/145以下                                          |
| 強内容日    | G数2000以上・RB1/270以下・合算1/135以下                                          |
| 出玉だけ強い日 | 差枚+800以上だが、RBが弱い、合算が弱い、またはG数不足                                        |

結果として、高内容日は53台日、良内容日は70台日、強内容日は30台日でした。

## 5. 完成した100点満点の狙い度ロジック

### ロジック名

**フォーチュンお花茶屋店_ネオアイムEX_沈み角度返済ロジック_v1**

### 基本思想

この店のネオアイムは、固定台番狙いではなく、以下を重視します。

1. 直近3日の沈み角度
2. 連敗数、特に4連敗
3. 直近3日のボーナス未露出感
4. 前日高内容不発の処遇未完了
5. 直近で出し切った台の回避
6. 履歴G数の信頼度

## 13. 最終結論

この機種では、**100点満点ロジック単体を主軸にするより、点数＋次点差＋沈み角度を重ねた段階条件を主軸にするべき**です。

最終判断は以下です。

| 項目          | 結論                                   |
| ----------- | ------------------------------------ |
| 100点満点ロジック  | 毎日の順位付けに使う                           |
| 段階的採用条件     | Webアプリ上の主軸にする                        |
| 自由度MAX条件    | 実戦では最優先してよい                          |
| 通常日/イベント日分離 | 特定日が全日「いいえ」のため作らない                   |
| 最も現実的な狙い方   | 1位または高点数台のうち、次点差25点以上＋沈み角度/返済未完が重なる台 |
| 見送り判断       | 次点差が小さい、危険条件あり、直近で出し切った台は見送り         |

## 12. 実戦での使い方

毎日の順位付けは、100点満点ロジックを使ってください。ただし、毎日1位だけではRB 1/332.4で、ネオアイムの本命としてはやや広すぎます。

実戦で打つ順番は次が現実的です。

1. **自由A/Bが出た台を最優先**
   4連敗以上＋1位＋次点差25以上系。件数は少ないが、56推定率が最も高い。

2. **Web条件の本命290以上を本命**
   1位＋次点差25以上＋90点以上。RB 1/285.0、合算1/136.6。

3. **強280・最本命270は強いが件数少のため過信しない**
   本当に他に良い候補がない日だけ強く使う。

4. **広め310・弱め300は“打てる候補”止まり**
   座る価値はあるが、56推定率30%未満も多い。

5. **前日高内容、前日+1500枚以上、直近3日+2000枚以上は原則見送り**
   データ上はかなり弱い。

## 13. 最終結論

この機種では、**100点満点ロジックを順位付けの土台にし、実戦採用は段階的採用条件と自由度MAX条件を優先**するのが最も現実的です。

| 判断                  | 結論                                                |
| ------------------- | ------------------------------------------------- |
| 100点満点ロジックを主軸にするべきか | 毎日の順位付けには主軸                                       |
| 段階的採用条件を主軸にするべきか    | 実戦採用の主軸                                           |
| 自由度MAX条件を主軸にするべきか   | 条件が出た日は最優先                                        |
| 実戦確認順               | 自由A/B → 本命290以上 → 強280以上 → 広め310/弱め300 → 危険条件チェック |

最終採用は次です。

```text
通常運用：1位＋次点差25以上＋90点以上
強い日：1位＋次点差30以上＋90点以上
最優先：1位＋4連敗以上＋5日角度≤-100＋次点差25以上
見送り：前日高内容、前日+1500枚以上、直近3日+2000枚以上
```
