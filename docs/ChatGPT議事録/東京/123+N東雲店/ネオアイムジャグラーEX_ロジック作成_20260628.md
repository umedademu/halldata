# 2. 高内容日の定義

ネオアイムジャグラーEXは、今回の指定どおり「設定5・6級に座れたか」を成功寄りの評価にしました。設定4以下は成功扱いしません。

各台の当日評価は、BIG確率とREG確率を設定1〜6の理論値に当てはめ、設定5・6推定率を算出しました。計算思想は、G数・BIG回数・REG回数から設定ごとの尤度を出し、正規化して設定5+6の確率を見る方法です。

今回の実務上の定義は以下です。

| 区分      | 定義                                 |
| ------- | ---------------------------------- |
| 高内容50   | 当日G数2,000G以上、かつ設定5・6推定率50%以上       |
| 強高内容70  | 当日G数2,000G以上、かつ設定5・6推定率70%以上       |
| 参考強ボーナス | RB1/300以下、合算1/140以下                |
| 危険な弱内容  | 十分なG数があり、RB1/400超、または設定5・6推定率30%未満 |

最終的な採用判断では、平均RBだけでなく、平均56推定率、中央値56推定率、56推定率50%以上の割合、56推定率30%未満の割合を重視しました。

# 12. 実戦での使い方

毎日の順位付けに使うものは、**100点満点ロジック**です。まず全台に点数を付け、1位、次点差、危険条件の有無を見ます。

条件が出た日だけ打つ本命ルールは、以下の順です。

1. **自由B_差枚角度最深**
   score>=85、rank=1、next_gap>=10、5日差枚<=-2,000、連敗5以下。

2. **最深沈み4-5連**
   score>=85、4〜5連敗、5日差枚<=-2,500、7日角度<=-0.15。

3. **自由A_深沈み返済**
   score>=90、4〜5連敗、5日差枚<=-2,500、21日返済未完。

4. **本物感ミックス**
   深沈みがなくても、7日合算1/130以下＋3日合算1/125以下＋前日大出しなしなら拾う。

Webアプリの条件列で確認する補助ルールは、段階的採用条件です。
「1位＋次点差10以上」は広めの本命、「本物感ミックス」は内容型本命、「自由B」や「最深沈み4-5連」は実戦最優先にしてください。

見送りは、前日大出し、処遇完了14、7連敗以上、低稼働が重なる時です。特に前日+1,500枚以上の台は、スコアが高くてもかなり割り引きます。

# 13. 最終結論

この機種では、**100点満点ロジックを主軸に“順位付け”し、実際に座るかは自由度MAX条件で決める**のが最も現実的です。

| 判断         | 結論                                                                     |
| ---------- | ---------------------------------------------------------------------- |
| 100点満点ロジック | 毎日の候補抽出・順位付けに使う                                                        |
| 段階的採用条件    | Webアプリ上で座る価値の強弱を表示する                                                   |
| 自由度MAX条件   | 実戦で最優先。特に自由B_差枚角度最深                                                    |
| 通常日/特定日分離  | 分けない。全日共通ロジックのみ                                                        |
| 実戦確認順      | 1. 自由B → 2. 最深沈み4-5連 → 3. 自由A → 4. 本物感ミックス → 5. 1位＋次点差10以上 → 6. 危険条件確認 |

最終採用は、**自由B_差枚角度最深**を最優先。次点で、**最深沈み4-5連**、**自由A_深沈み返済**、**本物感ミックス**です。
