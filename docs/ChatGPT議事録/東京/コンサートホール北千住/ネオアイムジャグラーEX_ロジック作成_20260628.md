## 2. 高内容日の定義

ネオアイムジャグラーEXは、平均機械割よりも**設定5・6級に座れたか**を最重要にしました。設定5・6推定率は、BIG/REGの設定別確率を使い、各設定の尤度を正規化して算出しました。元プロンプトのネオアイム特例では、設定5・6級を成功、設定4以下を失敗扱いにし、REGと合算を重視するよう指定されています。 設定別ボーナス確率と推定率の計算式も、元プロンプトの指定に従っています。

今回の定義は以下です。

| ラベル         | 定義                             | 用途                 |
| ----------- | ------------------------------ | ------------------ |
| 高内容56       | G数3000以上、設定5・6推定率50%以上         | 前回高内容からの間隔、履歴判定    |
| 強高内容56      | G数3000以上、設定5・6推定率70%以上         | かなり強い履歴            |
| goodBonus   | G数3000以上、RB 1/310以下、合算 1/145以下 | ボーナス内容の本物感         |
| strongBonus | G数4000以上、RB 1/280以下、合算 1/135以下 | 直近で強く見せすぎた履歴       |
| 成功判定        | 設定5・6推定率が高いこと                  | 実戦評価の主軸            |
| 失敗判定        | 設定4以下推定率が高いこと                  | ネオアイムでは設定4も成功扱いしない |

参考検証として、CSV内の「設定」列も確認しましたが、最終ロジックには使っていません。元設定推定4.5以上の台は73台日あり、その全てが今回の再計算上でも設定5・6推定率50%以上でした。つまり元設定列と再計算した56推定率は整合していますが、元設定列は当日結果由来なので実戦用説明変数からは除外しました。

## 3. 見えた設定師のクセ

**1. 直近REG不足を返すクセがある。**

**2. 近隣の沈み・見せ場後の取り残されが効く。**
近隣7日差枚が大きく沈んでいて、さらに自台側にREG欠損や低G取り残されがある条件は、RB・合算・差枚がかなり改善しました。特に「近隣見せ場＋自台低G取り残し」は通常日でも比較的崩れにくく、自由度MAX条件として採用価値があります。

**3. 2日単位の深い沈みは効くが、14日凹みだけでは弱い。**
自台2日差枚-1,272枚以下、かつ直近7日strongBonusなしは91台日で、平均56推定率30.0%、56推定率50%以上24.2%。広めには使えますが、単独本命には足りません。

**4. 前日高G凹みは補助材料になる。**
前日5000G以上かつ差枚マイナス、さらに14日差枚が未返済という条件は平均56推定率29.1%まで上がりました。ただしRB 1/326.8で、単独本命には弱いです。

**5. 出た台を完全に切る店ではない。**
前日大勝でもRBが強ければ翌日も残るケースがあります。逆にBB寄り大勝は危険です。つまり「出たから終わり」ではなく、**REGと合算が伴った大勝は据え・継続候補**として扱うべきです。

## 12. 実戦での使い方

### 毎日の順位付け

まず100点ロジックで全台を並べます。ただし、**毎日1位に座る運用は不可**です。1位でも次差が小さい日は見送りです。

### 条件が出た日だけ打つ本命ルール

優先順位は以下です。

1. **最本命**：日別1位、85点以上、次点差12点以上
2. **主軸**：70点以上、強化条件2個以上、危険条件0個
3. **自由C**：近隣見せ場+低G取り残し
4. **補助**：7日REG不足>1/450、近隣薄+自台高G7
5. **広め**：70点以上のみ

### Webアプリの条件列で見る補助ルール

Webアプリでは、条件列に以下のように出すのがよいです。

| 表示名         | 実戦判断           |
| ----------- | -------------- |
| 広め70        | 候補入り。単独では座らない  |
| 弱本命70強2危0   | 基本的に座ってよい      |
| 本命85        | 件数注意だが強い       |
| 強88         | 空いていれば優先       |
| 最本命1位85次差12 | 最優先            |
| 自由C         | 点数より優先してよい本命補助 |
| 危険あり        | 原則見送りまたは順位下げ   |

## 13. 最終結論

この店舗のネオアイムは、**100点満点ロジックを毎日の土台にしつつ、実戦採用は段階的条件と自由Cを重視**するのが最も現実的です。

* **100点満点ロジック**：全台順位付けの土台として使う
* **段階的採用条件**：実戦で座る/見送る判断の主軸
* **自由度MAX条件**：特定パターンが出た時に点数より優先してよい
* **最も現実的な主軸**：70点以上＋強化2以上＋危険0
* **最上位狙い**：1位＋85点以上＋次点差12以上
* **避けるべき運用**：毎日1位を無条件で打つこと

通常日専用・特定日専用の別スコアは今回は作りません。特定日は明らかに全体成績が良いですが、条件別に分けると件数が少なく、専用点数表を作ると過剰最適化になりやすいです。全日共通スコアを使い、特定日は同じ条件の信頼度が上がる程度に扱うのが安全です。
