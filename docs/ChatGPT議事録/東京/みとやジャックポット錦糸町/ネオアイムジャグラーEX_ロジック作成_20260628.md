## 2. 高内容日の定義

ネオアイムジャグラーEXでは、今回の成功を**設定5・6級に座れたこと**と定義しました。設定4以下は今回の目的では失敗扱いです。

各台日の評価では、CSV内の`設定`列は使わず、以下を使って設定5・6推定率を計算しました。

* 総G数
* BB回数
* RB回数
* ネオアイムの設定別BB確率・RB確率
* 二項尤度による設定1〜6の正規化推定率
* `設定5・6推定率 = 設定5推定率 + 設定6推定率`

この計算方法は、ネオアイム特例の設定推定率計算に合わせています。

履歴上の「高内容」は、狙い度計算用の履歴ラベルとして以下で定義しました。

```text
高内容日 =
  G数1800以上 かつ 設定5・6推定率50%以上
  または
  G数2500以上 かつ RB 1/300以下 かつ 合成 1/145以下
```

ただし、最終評価では「高内容に当たったか」だけではなく、各採用条件の平均56推定率、中央値56推定率、RB確率、合算、差枚、機械割を併記しています。

## 13. 最終結論

この機種では、**100点満点ロジックは毎日の順位付け用**です。
実戦で主軸にすべきなのは、100点そのものではなく、**段階的採用条件＋自由度MAX条件**です。

最終優先順位は以下です。

```text
最優先：
  自由A / 最本命270
  = 1位＋強化3個以上＋危険0

次点：
  本命290
  = 65点以上＋強化2個以上＋14日差枚-4500以下＋1位＋次点差8以上

広く拾う：
  広め310
  = 65点以上＋14日差枚-3500以下＋1位＋次点差8以上

点数ロジックより優先してよい別枠：
  自由B
  = 直近10日合成1/180以上＋前回高内容から15〜21日
```

通常日専用・イベント日専用ロジックは今回は作らない方がよいです。
特定日は全体的に良いものの、検証可能な特定日が11日しかなく、専用ロジック化すると過剰最適化になりやすいためです。
