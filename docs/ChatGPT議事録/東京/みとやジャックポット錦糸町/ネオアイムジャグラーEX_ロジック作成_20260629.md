# 2. 高内容日の定義

ネオアイムジャグラーEXなので、成功判定は機械割よりも**設定5・6推定率**を主軸にしました。設定5・6級を成功、設定4以下を失敗寄りとして扱う指定と、BB/RBから設定1〜6の推定率を計算する指定に従っています。

| 指標                   | 定義                                        |
| -------------------- | ----------------------------------------- |
| 設定5・6推定率 `p56`       | ネオアイムの設定別BB/RB確率を使い、各台日のG数・BB・RBから対数尤度で計算 |
| 高内容 `highContent`    | `games >= 2000 && p56 >= 0.50`            |
| 強高内容 `strongContent` | `games >= 2500 && p56 >= 0.70`            |
| 良RB履歴                | `games >= 1500 && rbRate <= 300`          |
| 実績評価優先順              | RB確率 ＞ 合算確率 ＞ 機械割                         |
| 使わないもの               | CSVの`設定`列、`ブドウ`列、当日の差枚・G数・BB・RBなど未来情報     |

# 3. 見えたクセ

一番強かったクセは、**直近10営業日の大きな沈みを返すパターン**です。特に、10日累計差枚が-4500枚以下まで沈んだ台は、通常候補全体のRB 1/387.7から、RB 1/309.1まで改善しました。

さらに、そこへ「BBも弱い」「直近2日も沈んでいる」「沈みの底が深い」「直近の高内容が薄い」といった追加根拠が重なるほど、RB・合算・差枚が改善しました。最本命条件ではRB 1/259.6、合算1/128.3、平均差枚+492.7枚、機械割105.61%でした。

逆に、前日+1000枚以上、直近7日で高内容2回以上、危険条件2個以上は弱く、処遇済み・見せ場済みのサインとして扱う方がよさそうです。

# 11. 実戦での使い方

優先順位は次の順です。

1. `見送り：危険2以上`に該当した台は避ける。
2. `RB270最本命：10日大凹み＋4日BB弱`を最優先。
3. `RB280強：2日連続沈み＋28日底`は点数ロジックより優先してよい。
4. 次に`RB290本命`、`RB300弱め本命`。
5. `RB310広め`は候補がない日の入口。単独では本命扱いしない。
6. `score`や`rank`は毎日の並び替え用。条件ラベルの方を重視する。

# 12. 最終結論

この店舗のネオアイムは、**毎日1位を打つロジックでは弱く、10日大凹み・2日連続沈み・BB弱化を組み合わせた条件狙いが現実的**です。

主軸は、100点満点ロジック単体ではなく、以下の順に確認するのが最も実戦向きです。

```text
見送り：危険2以上
↓
RB270最本命：10日大凹み＋4日BB弱
↓
RB280強：2日連続沈み＋28日底
↓
RB290本命 / RB300弱め本命
↓
RB310広め
↓
score・rank・topGapは補助
```

# 3. ネオアイム評価指標

ネオアイムジャグラーEXは、設定5・6級だけを成功扱い、設定4以下は失敗寄りとして扱う。

設定5・6推定率 p56：
G、BB、RBから、ネオアイムの設定別BB/RB確率を使って設定1〜6の対数尤度を計算し、正規化する。
p56 = 設定5推定率 + 設定6推定率
p4minus = 1 - p56

CSVの「設定」列と「ブドウ」列は、最終ロジックの説明変数に使わない。
採用条件は、RB確率、合算、設定5・6推定率、差枚、機械割のバランスで評価する。
優先順は、RB確率 ＞ 合算確率 ＞ 機械割。

# 4. 指標定義正本

| 指標名 | 計算式 | 使う履歴範囲 | 欠損・低G数の扱い | 未来情報を含まない理由 |
|---|---|---|---|---|
| historyDays | 同一台番で予測日までに存在するCSV営業日数 | 予測日以前全履歴 | 21未満はスコア0、採用対象外 | 予測日までの過去だけ |
| diffN | 同一台番の予測日を含む直近N営業日の差枚合計 | N=1,4,10,14,28など | CSV欠損日は数えない | 実績日の差枚は使わない |
| gamesN | 同一台番の予測日を含む直近N営業日のG数合計 | N=1,7など | 低G数も合計。ただしgames7<3000は危険 | 実績日のG数は使わない |
| bbN | 同一台番の予測日を含む直近N営業日のBB合計 | N=4など | 0あり | 実績日のBBは使わない |
| rbN | 同一台番の予測日を含む直近N営業日のRB合計 | N=4など | 0あり | 実績日のRBは使わない |

| combinedN | gamesN / (bbN + rbN)。BB+RB=0ならInfinity | N=4など | 0回ならInfinity | 予測日以前のみ |
| p56 | 当該過去台日のG/BB/RBから算出する設定5・6推定率 | 過去台日単位 | 低G数でも算出するが、games7危険で補正 | 過去日の結果は予測時点で既知 |

| neg1000Count5 | 直近5営業日でdiff <= -1000の件数 | 予測日を含む5営業日 | 0可 | 実績日は使わない |
| maxDiff2 | 直近2営業日の差枚最大値 | 予測日を含む2営業日 | maxDiff2<=-500は2日とも-500以下 | 実績日は使わない |

| lossStreak | 予測日から遡って差枚<0が連続する日数 | 予測日以前 | 0可 | 実績日は使わない |
| boostCount | 下記7条件の該当数 | 予測日以前 | 0〜7 | 過去情報のみ |
| dangerCount | 下記5条件の該当数 | 予測日以前 | 0〜5 | 過去情報のみ |
