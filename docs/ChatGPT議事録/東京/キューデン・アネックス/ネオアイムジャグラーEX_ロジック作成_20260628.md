## 2. 高内容日の定義

ネオアイムは設定5・6級だけを成功扱いし、設定4以下は失敗扱いする前提で評価しました。これはプロンプト内でも、ネオアイムでは設定5・6級に座れた割合を最重要指標にする指定があるためです。

各台日のG数・BB・RBから、設定1〜6のボーナス確率を使って設定推定率を再計算しました。設定5・6推定率は「設定5推定率＋設定6推定率」として扱っています。

この分析での実用定義は以下です。

| 判定        | 定義                        |
| --------- | ------------------------- |
| 高内容日      | G数3000以上、かつ設定5・6推定率50%以上  |
| 強高内容日     | G数3000以上、かつ設定5・6推定率70%以上  |
| 内容評価の優先順位 | RB/REG確率 ＞ 合算確率 ＞ 機械割     |
| 機械割       | 100 + 総差枚 ÷ 総G数 ÷ 3 × 100 |

## 12. 実戦での使い方

## 13. 最終結論

この店舗のネオアイムは、**100点満点ロジック単体を主軸にするより、100点ロジックで順位を作り、次点差と自由MAX条件で最終判断する** のが現実的です。

| 判断         | 結論                                     |
| ---------- | -------------------------------------- |
| 100点満点ロジック | 毎日の順位付けの土台として使う                        |
| 段階的採用条件    | 実戦判断の主軸。特に1位＋次点差5点以上、7点以上              |
| 自由度MAX条件   | 条件が出た日は点数より優先可                         |
| 通常日/特定日専用  | 作らない。31特定日では過剰最適化リスクが高い                |
| 最優先確認順     | 自由最強270 → 1位差7+ → 1位差5+ → 1位差2+ → 1位のみ |
