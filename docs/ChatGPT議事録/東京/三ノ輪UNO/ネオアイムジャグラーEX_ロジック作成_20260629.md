# 3. ネオアイム設定推定率

ネオアイムジャグラーEXでは、設定5・6級だけを成功、設定4以下を失敗寄りとして扱う。

設定別確率：
| 設定 | BIG確率 | REG確率 | 合成確率 |
|---|---:|---:|---:|
| 1 | 1/273.1 | 1/439.8 | 1/168.48 |
| 2 | 1/269.7 | 1/399.6 | 1/161.02 |
| 3 | 1/269.7 | 1/331.0 | 1/148.61 |
| 4 | 1/259.0 | 1/315.1 | 1/142.15 |
| 5 | 1/259.0 | 1/255.0 | 1/128.49 |
| 6 | 1/255.0 | 1/255.0 | 1/127.50 |

計算方法：
G=総G数、B=BB、R=RB。
各設定のBIG確率をpB、REG確率をpRとする。

logWeight =
logC(G,B) + B*log(pB) + (G-B)*log(1-pB)
+
logC(G,R) + R*log(pR) + (G-R)*log(1-pR)

最大logWeightを引いてexpに戻し、全設定合計が1になるよう正規化する。

p56 = p5 + p6
p4lower = p1 + p2 + p3 + p4

actual_high50 = games >= 3000 && p56 >= 0.50
actual_high70 = games >= 4000 && p56 >= 0.70

注意：
判定当日のp56はバックテスト評価用。
スコア計算・採用条件では、判定当日以前に分からない未来情報を使わない。
過去日のp56は、prevP56、actualHigh50Count7、daysSince_high50などの履歴指標として使ってよい。
