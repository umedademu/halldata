# 三ノ輪UNO・ネオアイムジャグラーEX 狙い台ロジック

今回の目的は、CSVから「高設定を入れる場所のクセ」を分析し、翌日の狙い台を決めるための100点満点ロジックを作ることです。依頼文では、CSVをもとに設定師のクセを分析し、翌日狙いの「狙い度」ロジックを作ることが明示されています。
また、最新日の行は営業途中の可能性があるため除外し、「狙度」「次差」「ブドウ」「設定」などは最終ロジックの説明変数に使わない、という条件に従いました。 当日以降のG数・BB・RB・差枚・設定などの未来情報も、狙い度計算には使っていません。

## 2. 高内容日の定義

ネオアイムジャグラーEXは特例として、設定5・6級に座れた割合を最重要指標とし、設定4以下は失敗扱いにする前提で評価しました。
設定推定率は、G数・BIG回数・REG回数から、設定1〜6それぞれのBIG確率とREG確率を使って対数尤度を計算し、設定5＋設定6の推定率を `設定5・6推定率` として扱いました。

## 3. 設定師のクセの仮説

強く見えた順です。

### 1位：沈み返し＋直近ボーナス内容の本物感

最も使いやすかったのは、単なる凹みではなく、

* 直近7日または14日で沈んでいる
* 直近5日の合算が悪くない
* 過去に完全放置ではなく、ある程度内容を見せている
* そのうえでまだ返済未完了に見える

という形です。

特に `直近5日合算1/154以下 × 深沈み` は、実測RB 1/294.3、合算1/139.8、平均設定5・6推定率36.4%まで改善しました。ネオアイムとしては、単純な機械割よりこの「RB・合算・56推定率の同時改善」を重視すべきです。

### 2位：前日RBが極端に見えていない高スコア台

`score>=45 × 前日RB 1/450以上` は、77台選択でRB 1/309.6、平均設定5・6推定率31.9%でした。
前日だけ見ると弱く見えるが、直近の沈み・処遇未完・過去内容が重なる台を返している可能性があります。

### 3位：直近2連勝後でも、危険条件がなければ残る

一般的な「出た台は下げ」ではなく、`score>=30 × 直近2連勝以上 × 危険0` がRB 1/271.9、平均設定5・6推定率40.8%まで上がりました。
ただし17台しかないため、「最本命級だが件数少」として扱うのが安全です。

### 4位：次点差は5〜6点から意味が出る

1位と2位の点差は、5〜6点以上でRB・設定5・6推定率が改善しました。
ただし次点差だけでは平均差枚が荒れるため、単独条件ではなく本命条件の補強に使うべきです。

### 5位：特定日は全体では少し強いが、専用ロジック化するほどではない

有効期間では、通常日がRB 1/372.2・平均56率22.4%、特定日がRB 1/355.0・平均56率23.6%でした。
特定日は島全体で少し良いものの、条件別では通常日の方が強いものもありました。件数も19日しかないため、通常日専用・イベント日専用ロジックは作らず、全日共通ロジックだけで運用する方が過剰最適化を避けられます。

## 5. 完成した100点満点ロジック

### ロジック名

`三ノ輪UNO_ネオアイムジャグラーEX_全日共通V1`

### 計算式

```text
狙い度 = max(0, min(100, 加点合計 - 減点合計))
```

通常日・特定日で点数式は分けません。
Webアプリでは、この全日共通ロジックを `機種別` 列に表示する想定です。

### 重視している要素

このロジックは、単純な凹み狙いではありません。
主軸は、

```text
沈み・返済未完了
＋ 直近ボーナス内容の本物感
＋ 前日見え方の悪さ
＋ 長期放置ではない間隔
− 処遇完了
```

です。

## 13. 最終結論

この機種では、**100点満点ロジックを単独の主軸にするより、100点ロジックで候補を並べ、自由度MAX条件で最終判断する方が現実的**です。

| 判断項目        | 結論                                             |
| ----------- | ---------------------------------------------- |
| 100点満点ロジック  | 毎日の候補順位付けに使う                                   |
| 段階的採用条件     | Webアプリの条件列で価値の強弱を表示する主軸                        |
| 自由度MAX条件    | 実戦で最優先。特に自由A・自由C                               |
| 通常日専用ロジック   | 作らない                                           |
| イベント日専用ロジック | 作らない                                           |
| 実戦確認順       | 自由A/C → 本命RB290型/強RB280型 → 100点順位 → 次点差 → 危険条件 |

最も現実的な運用は、

```text
機種別100点ロジックで上位候補を出す
→ 自由A・自由C・本命RB290型が出ている台を優先
→ 危険条件2個以上、または高点でも本命根拠なしは見送る
```

です。

最後に、依頼文の指定どおり、Codexへ単独で貼り付けられる実装依頼を1つのコードブロックでまとめます。
